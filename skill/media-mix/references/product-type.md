# 제품 유형 — 목적형 / 발견형 판별과 채우는 순서

카드 1-다에서 짐작하고 ✋ 1에서 확인받는다. 카드 4가 채우는 순서를 쓴다.

- **기준(실무)**: 목적형은 검색광고 비중 ↑, 발견형은 디스플레이 · 피드 광고 비중 ↑. 다른 축은 더하지 않는다.
- **기본값일 뿐이다**: 마케터가 준 자료나 단서(지난 집행에서 검색광고가 잘 팔렸다, 광고주가 '보여 주면 팔린다'고 한다 등)가 있으면 이 표보다 그쪽을 먼저 따르고 근거를 1칸에 적는다.
- 표시: [실무] 실무 경험에서 온 것, [리서치] 공개 자료, [추론] 짐작 — [추론]은 기준 사례 확인 전 가안.

## 1. 정의
| | 목적형 | 발견형 |
|---|---|---|
| 구매 시작 | 필요가 생긴 뒤 검색한다 | 콘텐츠를 보다가 관심이 생긴다 |
| 고르는 방식 | 검색 → 비교 → 선택 | 발견 → 끌림 → 구매 |
| 늘리는 쪽 | 검색광고(네이버 · 카카오 · 구글 검색, 쇼핑검색). 한도는 검색량 | 디스플레이 · 피드(메타, 네이버 디스플레이 광고, 카카오모먼트, 유튜브) |
| 대표 예 [리서치] | 생필품, 기능성 제품 | 패션, 뷰티, 감성 상품 |

## 2. 판별 순서 — 짐작할 때
1. **브랜드 크기 × 예산** [실무]: 브랜드가 작고 예산이 크면 목적형, 반대면 발견형인 경우가 많다. 제품 · 브랜드마다 달라서 아래 신호로 확인한다.
   - [추론] 작은 브랜드가 큰 예산을 쓸 수 있는 건 제품 일반명 검색 수요(예: "탈모 샴푸")가 그 돈을 받아 줄 만큼 큰 시장인 경우가 많다. 큰 브랜드는 브랜드 검색이 이미 거둬져, 남는 작은 예산은 신제품을 보여 주는 데 쓰게 된다.
2. **제품 일반명 검색량** [추론]: 키워드 도구에서 브랜드명이 아니라 제품 일반명 · 분류명의 월 검색량. `검색량 × 클릭률 × 클릭 단가`가 예산의 상당 부분을 받아 줄 수 있으면 목적형 쪽. 브랜드 검색량은 검색광고 안에서 브랜드 키워드 · 브랜드검색 몫을 정할 뿐이다.
3. **구매 계기** [리서치 · 추론]: 문제가 생겨서 찾는다(교체, 고장, 증상, 정해진 날짜) → 목적형 / 보고 갖고 싶어진다(스타일, 분위기, 새로움) → 발견형.
4. **상품 페이지 · 쇼핑 검색 형태** [추론]: 가격 · 용량 · 스펙 비교가 중심이고 쇼핑검색에 가격비교로 묶여 있다 → 목적형 / 사진 · 착용 · 사용 장면이 중심 → 발견형.
5. **경쟁사 광고** [추론]: 메타 광고 라이브러리에서 같은 분류 경쟁사가 피드 광고를 많이, 오래 돌리면 발견형 신호.
6. **제품의 시기** [추론]: 처음 나왔을 때는 발견형으로 시작하고(아직 아무도 검색하지 않음) 검색이 쌓이면 목적형 쪽으로 옮겨 간다. 새 개념 제품은 분류가 목적형이어도 초기엔 발견형.

신호가 엇갈리면 **'경계'** — 두 순서의 중간으로 두고 표시한다. 얼마나 옮길지는 판단 차이(마케터가 정함), 근거는 1칸에.

### 분류별 기울기 [추론, 확인 전]
| 분류 | 기울기 | 예외 · 주의 |
|---|---|---|
| 생필품 · 소모품(세제, 휴지, 필터 · 리필) | 목적형 | 새 형태 제품(예: 시트 세제)은 초기에 발견형 |
| 기능성 · 문제 해결(탈모, 여드름, 제습, 방충) | 목적형 | 새 성분 · 유행 성분 제품은 발견형으로 시작 |
| 영양제 · 건강식품 | 목적형(증상 · 성분 검색) | 선물용 · 유행 제품은 발견형 섞임 |
| 가전 · 고가 비교 구매 | 목적형(모델명 · 스펙 비교) | 유튜브 리뷰 영향이 커서 발견형 몫도 리뷰형 영상으로 |
| 패션 · 잡화 | 발견형 | 기본템(흰 티, 정장 구두 등)은 목적형 |
| 뷰티 — 색조 · 신제품 | 발견형 | 동영상 · SNS 탐색이 많음 |
| 뷰티 — 기초 · 기능 스킨케어(선크림, 진정) | 목적형 쪽 | 리뷰 영상 · 화장품 정보 앱으로 비교 |
| 홈데코 · 인테리어 소품 · 감성 상품 · 굿즈 | 발견형 | — |
| 식품 — 간편식 신상 · 디저트 | 발견형 | — |
| 식품 — 품목 정해진 것(쌀, 한우, 과일 선물세트) | 목적형 | 명절 · 선물 시기엔 목적형이 더 강해짐 |
| 반려동물 — 사료 · 모래 | 목적형 | 장난감 · 디자인 용품은 발견형 |
| 유아동 — 필수품(기저귀, 물티슈) | 목적형 | 디자인 육아용품 · 장난감은 발견형 |
| 상담 · 신청형 서비스(교육, 시공, 금융) | 목적형 | 검색 단가가 높아 리드 단계(G)와 같이 본다 |

- 대행사 자료의 "신규 · 인지도 낮은 브랜드는 인지형 매체 70% 이상" 기준은 **브랜드 검색** 기준이고, 목적형 / 발견형은 **제품 일반명 검색**으로 가른다 [추론]. 작은 브랜드가 목적형이면 브랜드 키워드가 아니라 일반명 키워드로 검색광고를 키운다.
- 네이버 쇼핑검색 안에도 추천 지면이 섞여 있어, 쇼핑검색을 순수 목적형 검색광고로만 보지 않는다. 의류는 찾는 일이 포털보다 쇼핑 앱 안 검색에서 일어난다(판매처 안 검색은 네 매체 밖).

## 3. 채우는 순서 (카드 4)
제품 유형마다 '채우는 순서'로 금액을 정한다. 출발 비중 범위는 아직 없다(가안: 순서로 금액, 비중은 결과로).

| | 목적형(검색광고 비중 ↑, 한도 = 검색량) | 발견형(디스플레이 · 피드 비중 ↑, 한도 = 예산) |
|---|---|---|
| **평시** | 브랜드검색 상품(고정분, 월 1,000회 이상일 때) → 브랜드 키워드 → 일반 키워드를 검색 한도까지(지난 기록 ROAS가 목표에 못 미치는 줄이면 한도까지 채우지 않고 근거를 적는다 — 사용자 자료로 바꾼 것) → 남는 돈은 신규 유입. 예: 생필품 · 기능성 · 영양제 · 사료 | 브랜드 키워드 검색 지키기 → 리타겟(얼마나 쓰일지는 매체가 정함 — 덜 쓰이면 신규 유입으로) → 남는 돈은 신규 유입(메타 · 네이버 디스플레이 · 카카오 비즈보드 · 유튜브). 예: 패션 · 색조 · 홈데코 · 디저트 |
| **행사**(구간 블록마다) | 예열에 신규 유입으로 알리고 검색 수요를 키운다 → 본 행사에 검색광고 한도(평시 검색량 × 시즌 배수)를 늘린다 → 마무리는 리타겟. 예: 명절 선물세트, 생필품 대용량 행사, 여름 제습기 시즌 | 예열을 길게 해 피드 · 디스플레이로 알리고 리타겟 모수를 쌓는다 → 본 행사에 피드 판매 목적 + 리타겟 크게. 자료를 늦게 받으면 리타겟 몫이 커진다. 예: 뷰티 · 패션 시즌 세일, 가을 · 겨울 아우터 |
| **장기** | 달마다 그 달의 모양(평시 / 행사)의 순서를 따른다. 전략안 방향 비중이 한도를 넘으면 한도까지만(가안) | 같음 |

- 구글 검색은 IT · 기업 대상 · 해외 판매 업종에서 몫이 커진다.
- **경계 제품**: 두 순서의 중간으로 두고 '경계'로 표시.

## 4. 순서에 덧씌우는 것
- **진단이 덧씌우는 방향**: 유입 부족이면 신규 유입 ↑. 신제품 알리기면 목적형이어도 처음엔 발견형 순서(노출 우선). 재구매 늘리기면 리타겟 ↑. 단가 상승이면 비중은 두고 같은 역할 안에서 옮긴다. 재구매 중심 광고주를 따로 두지 않는다 — 대행사 패스에서는 리타겟 금액이 모수에 묶여 배분 모양을 바꿀 만큼 커지기 어렵다.
- **제품군이 섞인 광고주**(예: 기초는 목적형, 색조는 발견형): 주력 제품군별로 유형을 정하고, 금액을 제품군 비중(매출 비중이나 광고주가 밀려는 비중)대로 나눠 각 순서를 따른 뒤 합친다. 3칸 표에 제품군 열.
- **새 광고주(처음 거래)가 바꾸는 것**(10/30)
  1. 성과가 빨리 보이는 쪽으로 기운다 — 검색광고 · 리타겟처럼 구매가 빨리 나오는 쪽을 먼저 채운다(발견형도 구매 의도 일반 키워드까지, 리타겟도 따로 둔다. 모수는 보지 않는다 — 리타겟은 종속 변수, 11/3).
  2. 신규 유입은 전환(판매) 목적 상품으로 모은다. 단 신제품은 노출 우선이 앞선다.
  - 신규라고 데이터가 없는 것은 아니다(다른 대행사에서 옮겨 오면 지난 기록이 있다). 데이터 유무는 따로 본다. 기록이 없으면 '가설'로 적는다.
  - 얼마나 기울이는지 숫자는 정하지 않았다(가안).
- **상시 광고주가 신제품으로 예산을 늘리는 경우**(가안): 새 입구를 만들지 않는다. 입구는 상시, 기존 제품군 + 신제품 제품군으로 나눈다. 신제품 몫은 처음엔 발견형 채우는 순서 · 진단 '신제품 알리기'로. 기간 모양은 고정한 틀을 따른다.
