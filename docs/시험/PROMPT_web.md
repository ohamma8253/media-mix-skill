# 스킬 시험 지시 — 웹 대화판 (media-mix)

너는 `media-mix` 스킬을 **웹 대화 환경(Claude 웹 · ChatGPT)처럼** 시험하는 에이전트다. 스킬은 시험 공간의 `.claude/skills/media-mix/`에 있다(다른 곳에 두었으면 시험 지시에 적힌 경로). `SKILL.md`와 그 안에서 가리키는 `references/` 문서를 읽고 안내를 그대로 따른다.

## 진행하는 법
- 웹 대화처럼 진행한다: 셸 명령 · 스크립트 실행 · 계산 도구를 쓰지 않는다(계산은 직접 한다). **웹 검색도 쓰지 않는다**(시나리오의 광고주는 가상이라 웹에 없다 — 스킬이 '웹 검색 도구가 없을 때'로 가는 길을 따른다).
- 사용자가 파일 · 캡처를 올리면 그 파일을 읽는 것은 '업로드받음'으로 보고 허용한다. 시나리오가 "[파일 올림: …]" · "[캡처 올림: …]"이라고 한 때에만, 그 파일만 읽는다(경로는 시나리오 폴더 기준).
- 사용자는 실행 지시에 적힌 시나리오 파일(`test/scenarios/<시나리오>/scenario.md`)의 사람이다. 실제 사람에게 묻지 말고, 질문할 때마다 시나리오에서 사용자가 할 답을 찾아 쓴다. 시나리오의 '답하는 법'이 있으면 반드시 지킨다.
  - 대화의 시작은 시나리오의 '처음 하는 말' 그대로다.
  - 사용자는 **물은 것만** 답한다. 🔒 표시된 값은 스킬 쪽이 그 값을 묻기 전에는 절대 꺼내지 않는다. 질문 괄호의 "(…이 보이면 함께)"도 물은 것으로 친다.
  - 시나리오에 없는 것은 "모르겠어요"다. 사용자 답을 지어내거나 시나리오 값을 바꾸지 않는다.
  - '나중에 하는 말'은 시나리오에 적힌 때(앞 판의 다음 작업까지 끝난 뒤)에 한 번 한다. 그 뒤 이어서 끝까지 진행한다.
- 사람에게 확인받으려고 멈추지 말고 끝까지 진행한다(✋ 확인 차례도 시나리오의 답으로 넘어간다).
- 스킬 쪽과 사용자 쪽을 섞지 않는다. 스킬 쪽은 사용자가 말하거나 올린 것만 안다 — 시나리오 문서의 나머지 내용을 스킬 쪽 판단에 쓰지 않는다.
- **이 작업 공간 밖은 읽지 않는다.** 스킬 폴더 · 이 지침 · 내 시나리오 폴더만 읽는다. 다른 시나리오 폴더와 `results/`의 다른 결과는 열지 않는다.
- 비밀번호 · 계정 값은 받지도 쓰지도 않는다(스킬 원칙 10). 외부로 보내거나 저장하지 않는다.

## 결과물 (실행 지시에 적힌 폴더 `results/<시나리오>-<모델>/`)
- `transcript.md`: 대화 전체. 스킬 쪽 차례는 `스킬:`, 사용자 쪽 차례는 `사용자:`로 시작한다. 파일 · 캡처를 올린 차례는 `사용자: [파일 올림: …]`처럼 적는다. 스킬이 낸 진행 줄 · 표 · 계획안도 그대로 남긴다.
- `final.md`: 마지막에 사용자에게 준 결과 전부 — 산출물 한 벌(1 머리표 · 2 입력 카드 · 3 방향 두 장 · 4 계획안 일곱 칸 · 5 점검 결과 · 6 메시지 · 7 기록 · 8 다음 뎁스, 해당 없음은 '해당 없음'으로). 판이 여럿이면(1판 · 2판, 첫 달 · 둘째 달) 모두 순서대로.
- `notes.md`: 스킬을 따르며 헷갈린 곳 · 막힌 곳 · 스킬에서 고칠 곳(카드 번호와 함께, 짧게). 사용자 역을 하며 시나리오에 답이 없어 "모르겠어요"로 넘긴 질문도 적는다.
- 끝나면 빈 `DONE` 파일을 만든다.
