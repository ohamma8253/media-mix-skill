# 시험 시나리오 s3 — 사용자(새 광고주 '누비결'을 맡은 대행사 마케터)가 아는 것

이 문서는 '사용자'의 머릿속이다. 스킬을 진행하는 쪽은 사용자에게 질문할 때마다 여기서 사용자가 할 답을 찾아 쓴다.
- 여기에 없는 것을 물으면 "모르겠어요"라고 답한다.
- **사용자는 묻는 것만 답한다.** 아래 값은 모두 '물으면 답하는 것'이다. 질문 괄호 안에 "(…이 보이면 함께)"로 붙은 것도 물은 것으로 친다.
- 🔒 표시는 **묻지 않으면 끝까지 먼저 말하지 않는 것**이다(채점에 쓰인다).
- 판단(진단 · 배분 · 상품 선택)은 사용자가 먼저 내놓지 않는다. 스킬이 낸 안을 확인하거나 고칠 뿐이다.
- 모든 광고주 · 숫자는 가상이다. 웹에서 찾을 수 없다.

## 처음 하는 말
"새 광고주인데 블랙프라이데이 당일 11/27 하루만 크게 켜 달래요. 예산은 1,000이에요."

## 사용자에 대해
- 대행사 퍼포먼스 마케터. 누비결(여성 아우터 자사몰, 카페24)은 11/10에 처음 문의한 광고주다.
- 오늘은 **2026-11-11(수)**.
- 광고주가 보내 준 캡처(이벤트 관리자 · 메타 최근 30일 방문자)와 공개 화면(자사몰 · 키워드 도구)을 볼 수 있다. 광고 계정 권한은 아직 없다.
- 광고주 내부 데이터는 못 보고, 랜딩 · CRM도 못 바꾼다.

| 물음 | 답 |
|---|---|
| 상시인가 새 광고주인가 | 새 광고주 첫 제안 |
| 브랜드 · 주소 | 누비결, `https://nubigyeol.example`(가상) |
| 업종 · 주력 제품 · 가격대 · 파는 곳 | 여성 아우터(코트 · 패딩). 정가 15만 ~ 30만 원대. 자사몰(카페24)에서만 판다 |

| 사전 심의 업종인가 | 아니에요 |
| 🔒 객단가 | "광고주 숫자는 없어요. 제가 해 본 비슷한 광고주는 행사 때 할인가 기준 객단가가 9만 원쯤이었어요(여러 벌 사는 것 포함)." |
| 제품 유형 확인 | 스킬이 짐작을 보여 주면: "발견형 맞아요. 옷은 보고 사죠." 짐작 없이 물으면 "잘 모르겠어요." |

## 목표 · 예산 · 기간 · 조건 (물으면)
| 물음 | 답 |
|---|---|
| 목표 | 목표 ROAS **400%** |
| 광고주 고민 · 브리프 | "블프 당일 매출을 크게 내고 싶대요." |

| 예산 | **1,000만 원** |

| 기간 · 요청 | "11/27 하루만 켜 달래요." 다른 날을 써도 되냐고 물으면: "제안해 보면 광고주가 판단할 거예요." |
| 컨펌 받을 날 | 🔒 "11/18까지 정해야 해요." |

| 영상 소재 | **숏폼 영상 1편** 있다(인플루언서 착용 영상, 11/25 업로드분) |
| 금지 사항 | 없다 |
| 성과 기준 기본값을 보여 주면 | "네, 일단 그렇게요." |

## 달력 · 수요 (물으면)
| 물음 | 답 |
|---|---|
| 프로모션 자료 | 대상 — 아우터 전 품목 / 기간 — 11/27 하루 / 할인 — 50% / 콘텐츠 업로드 — 11/25 인플루언서 착용 영상. 받은 날 11/10 |
| 시즌 근거 | "작년 기록은 없어요." 데이터랩은 "안 봤어요" |
| 키워드 도구 — 브랜드명 | '누비결' **월 2,500회**, 월평균 클릭수 약 750회(클릭률 30%), 클릭 비용 300~400원 |
| 키워드 도구 — 일반 키워드 | "브랜드명만 봤어요." 다시 물으면 "그건 모르겠어요." |
| 🔒 네이버 브랜드검색 상품 가격 | "그 검색량이면 7일에 25만 원쯤이에요." |

## 확인 · 검토 차례
- 입력 카드 확인(✋ 1): "그대로 가요."
- 진단 확인(✋ 2): "네, 그렇게 봐요."(근거 없이 지어낸 값이 있으면 "그 숫자는 제가 드린 적 없어요"라고 한 번 짚는다)
- 계획안 검토(✋ 3): "좋아요, 광고주한테 보내 볼게요."
- 다음 작업: 스킬이 메시지 · 프로필을 이미 냈으면 더 필요한 것을 물을 때 "그건 괜찮아요." 아직 안 냈으면 "컨펌 메시지랑 요청 메시지 주세요."

## 나중에 하는 말 1 — 광고주 답 (1판의 다음 작업까지 끝난 뒤 한 번)
"11/14예요. 광고주 답이 왔어요. '4일 연속 좋습니다. 12/1에 앵콜 세일(40%)을 하루 더 하고, 예산은 1,200으로 올릴게요.'"

| 광고주 최종 답을 물으면 | "11/15에 이대로 좋다고 했어요." |
| 다음 작업 | 이미 냈으면 더 필요한 것은 "그건 괜찮아요." 안 냈으면 "컨펌 메시지랑 프로필 정리해 주세요." |
