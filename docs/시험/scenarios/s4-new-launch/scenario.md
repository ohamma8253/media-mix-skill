# 시험 시나리오 s4 — 사용자(새 광고주 '말랑목' 런칭을 맡은 대행사 마케터)가 아는 것

이 문서는 '사용자'의 머릿속이다. 스킬을 진행하는 쪽은 사용자에게 질문할 때마다 여기서 사용자가 할 답을 찾아 쓴다.
- 여기에 없는 것을 물으면 "모르겠어요"라고 답한다.
- **사용자는 묻는 것만 답한다.** 아래 값은 모두 '물으면 답하는 것'이다. 질문 괄호 안에 "(…이 보이면 함께)"로 붙은 것도 물은 것으로 친다.
- 🔒 표시는 **묻지 않으면 끝까지 먼저 말하지 않는 것**이다(채점에 쓰인다).
- 판단(진단 · 배분 · 상품 선택)은 사용자가 먼저 내놓지 않는다. 스킬이 낸 안을 확인하거나 고칠 뿐이다.
- 모든 광고주 · 숫자는 가상이다. 웹에서 찾을 수 없다.

## 처음 하는 말
"새 광고주 신제품 런칭이에요. 12/1에 무선 목 마사지기가 나오는데, 12월부터 2월까지 3개월 계획을 짜 달래요."

## 사용자에 대해
- 대행사 퍼포먼스 마케터. 말랑목은 11/5에 처음 문의한 광고주다.
- 오늘은 **2026-11-12(목)**.
- 메타 광고 관리자(출시 전 계정) · 공개 화면(자사몰 · 키워드 도구 · 데이터랩)을 볼 수 있다.
- 광고주 내부 데이터는 못 보고, 랜딩 · CRM도 못 바꾼다.

## 확인 · 검토 차례
- 입력 카드 확인(✋ 1): "그대로 가요."
- 진단 확인(✋ 2): "네, 그렇게 봐요."(근거 없이 지어낸 값이 있으면 "그 숫자는 제가 드린 적 없어요"라고 한 번 짚는다)
- 노출 우선(학습 하한을 못 채워 최적화 단계를 올리자는 등)을 상의하면: "네, 그렇게 가요."
- 계획안 검토(✋ 3): "좋아요."
- 다음 작업: 스킬이 메시지 · 프로필을 이미 냈으면 더 필요한 것을 물을 때 "그건 괜찮아요." 아직 안 냈으면 "컨펌 메시지랑 요청 메시지, 프로필 정리해 주세요."
