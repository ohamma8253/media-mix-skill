# 시험 시나리오 s2 — 사용자(새 광고주 '온결'을 맡은 대행사 마케터)가 아는 것

이 문서는 '사용자'의 머릿속이다. 스킬을 진행하는 쪽은 사용자에게 질문할 때마다 여기서 사용자가 할 답을 찾아 쓴다.
- 여기에 없는 것을 물으면 "모르겠어요"라고 답한다.
- **사용자는 묻는 것만 답한다.** 아래 값은 모두 '물으면 답하는 것'이다. 질문 괄호 안에 "(…이 보이면 함께)"로 붙은 것도 물은 것으로 친다.
- 🔒 표시는 **묻지 않으면 끝까지 먼저 말하지 않는 것**이다(채점에 쓰인다).
- 판단(진단 · 배분 · 상품 선택)은 사용자가 먼저 내놓지 않는다. 스킬이 낸 안을 확인하거나 고칠 뿐이다.
- 모든 광고주 · 숫자는 가상이다. 웹에서 찾을 수 없다.

## 처음 하는 말
"새 광고주 첫 제안이에요. 디퓨저 · 향초 파는 자사몰인데, 예산은 없고 목표 매출에 맞춰 제안해 달래요."

## 사용자에 대해
- 대행사 퍼포먼스 마케터. 온결은 10/29에 처음 문의한 광고주다.
- 오늘은 **2026-10-29(목)**.
- 공개 화면(자사몰 · 네이버 쇼핑 검색 · 네이버 키워드 도구 · 데이터랩)은 볼 수 있다. 광고주 광고 계정은 아직 권한을 못 받았다.
- 광고주 내부 데이터는 못 보고, 랜딩 · CRM도 못 바꾼다.

## 광고주 · 제품 (물으면)
| 물음 | 답 |
|---|---|
| 상시인가 새 광고주인가 | 새 광고주 첫 제안 |
| 브랜드 · 주소 | 온결, `https://ongyeol.example`(가상) |
| 업종 · 주력 제품 · 가격대 · 파는 곳 | 디퓨저 · 향초. 대표 상품 3.2만 ~ 4.8만 원. 자사몰(카페24)에서만 판다 |
| 되는 것 고르기 | 둘 다 아님 |
| 사전 심의 업종인가 | 아니에요 |
| 🔒 실제 객단가 | "모르겠어요. 아직 못 받았어요." |
| 제품 유형 확인 | 스킬이 짐작을 보여 주면: "발견형이 맞는 것 같아요. 선물이나 분위기 보고 사는 거라서요." 짐작 없이 그냥 물으면: "잘 모르겠어요. 선물로 많이 산대요." |

## 목표 · 예산 · 기간 · 조건 (물으면)
| 물음 | 답 |
|---|---|
| 목표 | 자사몰 매출 **월 2,000만 원**, 목표 ROAS **300%** |

| 구매 전환율 | 모른다(지난 기록이 없다) |
| 예산 | **없음** — "목표 매출에 맞춰서 얼마 쓰면 되는지 제안해 달래요" |
| 금액 기준 | "수수료까지 포함해서 얼마인지 알려 달래요. 부가세는 별도로요." → **부가세 별도 · 수수료 포함** |
| 기간 | 12/1 ~ 12/31 |
| 컨펌 받을 날 | 🔒 "11/26까지 정하면 된대요." |
| 정해 둔 매체 · 비중, 꼭 쓸 · 뺄 매체 | 없다 |
| 영상 소재 | **없다.** 상세 페이지 이미지만 있다 |
| 금지 사항 | 없다 |
| 성과 기준 기본값을 보여 주면 | "네." 매출은 카페24 기준 |

| 구매 측정 | "메타 픽셀은 깔려 있다는데, 이벤트 관리자 구매 이벤트 화면은 못 봤어요." → 확인 못 함 |

| 키워드 도구 — 일반 키워드 | "브랜드명만 봤어요." 다시 물으면 "그건 모르겠어요." |

## 확인 · 검토 차례
- 입력 카드 확인(✋ 1): 객단가를 짐작으로 넣었으면 "네, 일단 그걸로요. 광고주한테 물어볼게요." 틀린 값이 없으면 "그대로 가요."
- 진단 확인(✋ 2): "네, 그렇게 봐요."(근거 없이 지어낸 값이 있으면 "그 숫자는 제가 드린 적 없어요"라고 한 번 짚는다)
- 계획안 검토(✋ 3): "좋아요."
- 다음 작업: 스킬이 메시지 · 프로필을 이미 냈으면 더 필요한 것을 물을 때 "그건 괜찮아요." 아직 안 냈으면 "컨펌 메시지랑 요청 메시지, 프로필 정리해 주세요."
- 목표 매출과 목표 ROAS를 같이 못 맞춘다고 하면: "알겠어요. 그대로 적어 주세요." 어느 쪽을 맞출지 고르라고 하면 "모르겠어요, 광고주랑 얘기해 볼게요."
