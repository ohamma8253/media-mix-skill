# 시험 시나리오 s1 — 사용자(포근밥 담당 대행사 마케터)가 아는 것

이 문서는 '사용자'의 머릿속이다. 스킬을 진행하는 쪽은 사용자에게 질문할 때마다 여기서 사용자가 할 답을 찾아 쓴다.
- 여기에 없는 것을 물으면 "모르겠어요"라고 답한다.
- **사용자는 묻는 것만 답한다.** 아래 값은 모두 '물으면 답하는 것'이다. 질문 괄호 안에 "(…이 보이면 함께)"로 붙은 것도 물은 것으로 친다.
- 🔒 표시는 **묻지 않으면 끝까지 먼저 말하지 않는 것**이다(채점에 쓰인다).
- 판단(진단 · 배분 · 상품 선택)은 사용자가 먼저 내놓지 않는다. 스킬이 낸 안을 확인하거나 고칠 뿐이다.
- 모든 광고주 · 숫자는 가상이다. 웹에서 찾을 수 없다.

## 처음 하는 말
"포근밥 11월 미디어믹스 짜야 해요. 8개월째 운영 중인 광고주예요."

## 사용자에 대해
- 대행사 퍼포먼스 마케터. 포근밥(반려견 사료 자사몰, 카페24)을 8개월째 운영한다.
- 오늘은 **2026-10-27(화)**.
- 네이버 검색광고 · 메타 광고 관리자 · 카카오 모먼트 관리자, 네이버 키워드 도구 · 데이터랩, 카페24 관리자(매출 · 주문 조회)를 볼 수 있다.
- 광고주 내부 데이터(주문 원장 · 고객 데이터 · 마진 · 재구매율)는 볼 수 없고, 랜딩 · 상품 페이지 · CRM도 바꿀 수 없다.
- 지난달에 정리해 둔 광고주 프로필은 없다("따로 정리해 둔 건 없어요").

## 확인 · 검토 차례
- 입력 카드 확인(✋ 1): 틀린 값 없다. "그대로 가요."
- 진단 확인(✋ 2): 스킬이 내놓은 진단에 "네, 그렇게 봐요."(무엇이든 그대로 동의. 단, 근거 없이 지어낸 값이 있으면 "그 숫자는 제가 드린 적 없어요"라고 한 번 짚는다)
- 계획안 검토(✋ 3): "좋아요."
- 다음 작업: 스킬이 메시지 · 프로필을 이미 냈으면 더 필요한 것을 물을 때 "그건 괜찮아요." 아직 안 냈으면 "컨펌 메시지랑 프로필 정리해 주세요."
