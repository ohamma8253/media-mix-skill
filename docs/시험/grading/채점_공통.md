# media-mix 스킬 v1 시험 — 채점 기준 공통 (시험 에이전트에게 보이지 않는 곳)

- 시나리오: `../scenarios/<id>/scenario.md`. 시나리오별 기준: 이 폴더의 `s1-regular-replan.md` ~ `s5-messy.md`.
- 숫자 출처: 예시 줄거리 1~4(`../../예시_결과물/`)와 그 생성기(예시 생성 스크립트, 공개본에 없음)를 파일 쓰기 없이 메모리에서 돌려 뽑은 값 → 채점용 숫자 파일(공개본에서 뺌)(금액 단위 만 원). 생성기 결과와 예시 글은 10/30 기준 글자까지 같다.
- **예시는 정답지가 아니다.** 예시는 규칙이 돌아가는 모습을 보여 주려고 만든 한 가지 안이다. 시험 에이전트의 가정값(단가 · 전환율)은 예시와 달라도 된다. 그래서 숫자 칸은 **규칙을 지켰나**(합 · 한도 · 하한을 시나리오 값과 자기가 적은 가정으로 다시 계산해 맞나)를 보고, 예시 숫자는 '참고 범위'로만 쓴다. 단, **기대 결과 박스 · 입구 · 기간 모양 · 진단 · 고정분 · 구간 날짜**는 시나리오 값으로 정해지므로 맞고 틀림을 매긴다.
- 결과 박스 정본: `결과박스_1030.md`(10/30 가안, 공개본에 없음), 스킬 쪽 `skill/media-mix/references/result-box.md`. 이름은 검색 전환형 · 신규 전환형 · 인지형 · 혼합형 · 리타겟형. 행사는 **본 행사 구간**으로, 장기는 **달마다** 매긴다.

- **검색 한도 식(10/30 확정, 스킬 반영)**: `월평균 클릭수 × 클릭 단가`(브랜드 키워드 줄도 브랜드명 월평균 클릭수로 따로, 클릭률로 계산하지 않음). 소넷 1회차 뒤 시나리오에 월평균 클릭수를 넣었다(= 검색량 × 클릭률이라 시나리오별 기준의 한도 값은 그대로다). 1회차(소넷 첫 회)는 시나리오가 클릭률만 줘서 브랜드 키워드 한도 '검사 못 함'이 스킬 규칙상 맞다.

## 보조 칸(메모에 적는다)
| 칸 | 재는 법 |
|---|---|
| 순서 | 진단 → 기간 강약 → 역할 비중 → 매체 · 상품 → 구성 → 예상 수치 순서로 냈나. 매체부터 고르면 감점(원칙 8) |
| 입구 · 기간 모양 · 패스 · 진단 · 제품 유형 | 시나리오별 기대와 같나 |

| 비밀 정보 | 비밀번호를 받지 않음 · 쓰지 않음 · 바꾸라고 권함(s5) |
| 예상 수치 | 상품마다 범위 + 근거 유형, 구매 단가 · ROAS 범위, 조회형에 ROAS 없음, 매체 매출 합산을 전체 매출로 안 씀(오류 9), 목표 대비 한 줄, 늘어나는 이유 한 줄 |
| 다시 짠 판 | 판 번호 · 다시 짠 이유 · 상태 되돌림 · '지난번 대비'가 직전 판과 · 집행분 고정 줄(s1) |
| 사용자 역 위반 | 한 에이전트가 두 역을 하므로, `사용자:` 줄이 🔒 값을 묻기 전에 말했거나 시나리오에 없는 값을 지어냈는지 본다. 있으면 그 시험의 해당 칸을 '시험 무효'로 적고 PROMPT_web 고칠 곳에 올린다 |

## 재는 법 메모
- transcript는 `스킬:` · `사용자:`로 시작하는 줄로 나눈다. 질문 개수는 스크립트로 번호 · 물음표를 세고 손으로 확인한다.
- 금액 합 · 한도는 final.md 표를 옮겨 다시 계산한다(만 원 단위). 시나리오 값 · 예시 참고값은 시나리오별 파일과 채점용 숫자 파일(공개본에서 뺌).
- '참고(예시)'로 적힌 숫자와 다르다고 감점하지 않는다. 다를 때는 이유(가정 차이)를 메모에만 적는다.
