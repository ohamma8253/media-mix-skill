## 1판 — 역제안안 (11/11)
### 정해지는 것(맞고 틀림을 매김)
| 항목 | 기대 |
|---|---|
| 입구 · 기간 모양 · 패스 | 새 광고주 · **행사**(프로모션 자료 필수 넷) · 대행사 |
| 진단 | 매출 규모 키우기(행사, 가설) |
| 제품 유형 | 발견형(짐작 → 확인받음) |
| 총액 · 금액 기준 | 1,000만 원 **매체비**(부가세 · 수수료 별도). 모든 금액 줄에 '매체비' 기준, 수수료는 따로 적음 |
| 역제안 | 요청(11/27 하루) → **하루짜리는 오류 3 ③(운영 2일 이하)** → 여러 날 연속으로 역제안(예시: 11/24~11/27 4일, 당일에 약 59%). 6칸에 요청 / 다르게 제안한 것 / 이유 / **광고주 결정: 대기**. 오류 6은 '예외로 통과(역제안 표시)' |
| 상태 | 광고주 확인 대기(역제안 결정이 남음) — '합의 완료'면 틀림 |
| 구간 | 예열(11/24~11/26, 콘텐츠 11/25 포함) + 본 행사 11/27. 본 행사 날짜 = 자료 날짜(오류 7 ②) |
| 고정분 | 브랜드명 월 2,500회 ≥ 1,000 → 브랜드검색 상품 가능. 🔒 가격(7일 25만 원)은 물어야 나온다. 묻지 않고 25를 적으면 단정, 넣고 가격을 '확인 못 함'으로 두거나 빼는 것은 맞음 |
| 결과 박스 | **신규 전환형(본 행사 11/27 기준)** — 예시 본 행사 575: 신규 유입 372(64.7%, 전부 판매 목적) · 리타겟 200(34.8%) · 검색광고 3(0.5%). 가르는 순서 1번. 꼬리표: 가설(기록 없음) |

### 한도 · 하한
| 식 | 값 | 참고(예시 1판) |
|---|---|---|
| 브랜드 키워드 한도 | 2,500 × 30% × 300~400원 = 월 22.5~30 → **4일분 3.0~4.0** | 4 |
| 리타겟 한도(분리한 메타 리타겟) | 8만 × 기간 노출 빈도(하루 1회 × 4일, 가안) × 노출 단가 8,000~9,500원 ÷ 1000 = **256~304** | 240 |
| 메타 신규 학습 하한 | 주 50건 × 가운데 구매 단가(예시 2.87만) × 세트 수(예시 2) = 주 287 → **4일분 약 164**(세트 1이면 82) | 656 |
| 시즌 배수 | 작년 기록 없음 → 쓰지 않음. 배수를 넣었으면 단정 | 없음 |

- 예시에서 **처음 안이 브랜드 키워드 한도를 넘어 고쳤다**(목차 '규칙의 빈틈' 1). 당일에 브랜드 키워드를 크게 넣었으면 오류 5 ①이 걸려야 한다.
- 리타겟 한도를 '월 노출 빈도'로 셌다면 며칠짜리 행사에 맞지 않는다 — 기간 노출 빈도(하루 1회 × 일수, 가안)를 썼나 본다.
- 운영 기간 2~3일 미만 줄(예: 당일 하루만 켜는 상품)이 남아 있으면 오류 3 ③ 놓친 것. 3일 몰기 상품은 통과.

### 걸려야 할 오류 · 확인할 처리
- 오류 3 ③ 하루짜리 → 역제안(위). 오류 6 → 역제안 표시로 '예외로 통과'.
- 오류 8: 객단가 9만 원은 '비슷한 광고주 · 가설', 전환율은 비슷한 광고주 범위, ③ 자기 기록 **검사 못 함**. 목표 대비: 목표 ROAS 400%에 메타 신규 줄의 **필요 전환율**(예시 약 2.6%, 비슷한 광고주 범위 위쪽 끝)을 목표 역산으로 적음.
- 8-1 숫자 순서: 전환율 신규 < 리타겟.
- 오류 4: 측정 확인됨(광고주 캡처) → 판매 목적 정상. 도달 · 릴스 등 노출형 줄에 ROAS 없음.
- 확인 못 함이어야 할 칸: 실제 객단가(7칸), 시즌 근거(없음), 일반 키워드 검색량, 지난 기록, 브랜드검색 상품 가격(묻지 않았을 때).
- 6 · 7: 컨펌 메시지(역제안 설명 포함, 뺀 매체와 이유 — 짧은 기간에 맞지 않는 상품), **데이터 · 일정 요청 메시지(새 광고주 필수)**, 7칸에 역제안 결정 기한.

## 2판 — 광고주 답 반영 (11/14, 나중에 하는 말 1)
| 항목 | 기대 |
|---|---|
| 머리표 | **2판**, 다시 짠 이유 = 광고주 수정 요청(앵콜 12/1 추가, 총액 1,000 → 1,200), 6칸 역제안 결정 = **수용** |
| 총액 | 1,200 매체비 = 고정분(있으면) + 구간. 예시: 25 + 예열 400 + 본 행사 575 + 평시 40 + 앵콜 160 |
| 행사 규칙 | 앵콜을 **하루짜리로 두지 않음**(예시 11/30~12/1 연속, 마지막 날 더), 행사 사이(11/28~11/29)를 끄지 않고 소액 유지 |
| 한도 | 리타겟 8일 × 하루 1회: 8만 × 8 × 8,000 ÷ 1000 = **512** ≥ 리타겟 줄. 브랜드 키워드 8일분 **6~8** |
| 학습 하한 | 메타 신규 8일분 약 327(세트 2) ≤ 신규 줄 |
| 🔒 성과 기준 합의 | 물었으면 "메타 보고 + 카페24 나란히, 판정은 카페24" → 합의 완료 조건 충족. **묻지 않고 '합의 완료'로 적으면 틀림**(합의 완료 = 역제안 결정 + 성과 기준 합의, SKILL.md 카드 10). 광고주 최종 답(11/15)을 물어 받았을 때만 '합의 완료' |
| 지난번 대비 | 1판 대비 열 |
| 결과 박스 | **신규 전환형(본 행사 11/27 기준)** — 예시 2판 본 행사는 1판과 같음. 월 전체도 신규 유입 70.6% · 판매 91% |

## 틀림의 예
- 요청대로 11/27 하루짜리 집행 · 역제안 표시 없음.
- 1판을 '합의 완료'로 / 2판에서 성과 기준을 묻지 않고 '합의 완료'.
- 앵콜을 12/1 하루만 · 행사 사이 이틀을 끔.
- 수수료를 총액에 섞음(금액 기준 혼동).
