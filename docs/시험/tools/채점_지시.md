# 채점 지시 — media-mix 스킬 시험 회차 하나

너는 시험 회차 하나를 채점한다. 한국어로 쓴다. 읽기만 하고, 쓰는 파일은 `<회차 폴더>/채점.md` 하나뿐이다.

## 읽을 것
1. 기준: `docs/시험/grading/채점_공통.md`와 시나리오별 기준 `grading/<시나리오>.md`, 숫자 참고 채점용 숫자 파일(필요한 부분만, 이름에 key가 들어가 공개본에서 뺌).
2. 시나리오(사용자가 아는 것): `docs/시험/scenarios/<시나리오>/scenario.md`.
3. 회차 결과: `<회차 폴더>/transcript.md` · `final.md` · `notes.md`.
4. 설계 미정 13건: `docs/시험/준비_보고.md`의 '예시와 숫자가 안 맞던 곳'. 이 13건에 걸린 차이(예: 줄거리 1 · 2판 박스 혼합형 vs 검색 전환형, 리타겟 빈도 8, 한도 단가 끝값)는 **'설계 미정'으로 따로 적고 스킬 실패로 세지 않는다.**
5. 스킬 본문이 필요하면 `skill/media-mix/`(읽기만).

## 매기는 법
- `채점_공통.md` 표의 칸을 그 판정 규칙대로 매긴다: 끝까지 갔나 · 결과 박스 · 금액 합 · 한도 · 하한 · 질문 4개 이상 발화 · 들은 것 밖 단정 · 확인 못 함 / 검사 못 함 처리 · 오류 11개 중 놓친 것. 보조 칸(순서 · 입구/기간 모양/진단/제품 유형 · 하지 않은 일 단정 · 비밀 정보 · 다시 짠 판 · 사용자 역 위반)도 본다.
- 금액 합 · 한도 · 하한은 final.md 표의 숫자를 **직접 다시 더하고 계산**한다(셸 · python으로 계산해도 된다). 시나리오 값과 회차가 적은 가정으로 계산한다. 예시 숫자와 달라도 규칙을 지켰으면 맞음이다.
- 질문 4개 이상 발화: 아래 '질문 수 기계 세기' 값을 출발점으로 쓰되, transcript를 보고 손으로 확인한다(번호 하나 = 하나, 화면 숫자 목록 = 하나, "(…이 보이면 함께)" 괄호는 세지 않음).
- 들은 것 밖 단정은 곳마다 transcript 위치(차례 번호나 인용 한 줄)를 적는다. 🔒 값을 묻기 전에 `사용자:`가 꺼냈으면 '사용자 역 위반'.
- 시나리오가 시험 도중 바뀐 경우(지시에 적힘)는 그 차이를 감점하지 않고 메모한다.
- 판정은 맞음 / 부분 / 틀림 / 해당 없음 중 하나와 이유 한 줄.
