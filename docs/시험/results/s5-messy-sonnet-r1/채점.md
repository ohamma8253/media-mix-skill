## 스킬에서 고칠 곳(이 회차 증거)
notes.md에서 맞다고 확인한 것(번호는 notes.md의 번호):
- notes 1 · 2: 금액 기준 '걸림(미해결)'은 SKILL 229행(가안)으로 처리됐다. 머리표 상태('광고주 확인 대기')와 금액 기준 단독 차례를 한 번 더 두는 쪽만 정리하면 된다. 이번엔 한 차례가 늘었다.
- notes 3: 진행 중인 달('10/26까지 실적 + 예약분') 처리 규칙과 8→9월 보조 진단 문서화. 이번엔 사용자가 네이버만 답했고 메타 · 카카오 기준일은 묻지 않고 '확인 못 함'으로 넘겼다.
- notes 4: 키워드 도구 열 이름(클릭수 / 클릭률). 현재 SKILL 119 · 127행에 이미 반영된 상태이고, 이 회차는 옛 캡처를 봤다.
- notes 6: ★ 가설 표시가 거의 모든 줄에 붙는다(추세를 반영하면 끝값이 기록 밖). 추세 반영 끝값과 증액으로 기록을 넘는 값을 구분하는 규칙이 필요하다.
- notes 7: '이벤트 관리자 권한 없음 · 광고 관리자에 구매는 나옴'을 판정표에 올릴 곳. 이번엔 보수적으로 '확인 못 함'이라 채점 기준과 맞다.
- notes 12 · 13: 컨펌 메시지 중복 출력, 1칸 '확인 못 함 목록' vs 6절의 내부 칸 금지. 1칸에 '반영 안 함'만 두고 확인 못 함은 7칸으로 넘긴 처리가 규칙에 맞다.

채점하며 찾은 것:
- 컨펌 메시지에 금액 기준이 빠졌다. SKILL 229행은 '걸림(미해결)'을 7칸 첫 줄과 컨펌 메시지의 '결정 · 확인 부탁'에 넣으라고 하는데, 이 회차의 컨펌 메시지 본문에는 금액 기준이 없고 데이터 요청 메시지 1번과 안내 문장에만 있다. 마지막 문장 "구매 측정 확인과 요청 자료에 따라"가 그걸 대신한다.
- 광고주용 본에 내부 말이 섞였다. 머리표 "상태: 내부 검토 완료(… 아래 점검 참고)"는 내부본의 점검을 가리키고, 1칸의 "마케터 확인", 6칸의 "(문턱값은 마케터가 정함)", 5칸의 "AI 추정" · "★ 가설"도 있다. 광고주용 본에는 상태 외 내부 칸을 넣지 않는다(plan-template 17행). 복사해 보낼 때 걸러야 한다.
- 컨펌 메시지 5번 "구글과 유튜브 … 지난 기록 없음"은 구글 사용 여부가 '확인 못 함'인 상태와 표현이 어긋난다("받은 기록에 없음"이 정확하다).
- 학습 하한 식의 주 수(4.29)와 결과(447)가 한 칸 어긋난다(448). 결론은 같다.
