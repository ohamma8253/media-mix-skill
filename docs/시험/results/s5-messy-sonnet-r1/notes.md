# 시험 메모 — s5-messy (스킬 쪽에서 헷갈린 곳 · 고칠 곳)

## 스킬에서 고칠 곳
1. **카드 9 오류 1 ③ vs 진행 원칙 3 충돌.** 1칸 금액 기준이 비면 규칙표는 '걸림'(필수 칸), 원칙 3은 모르는 값을 쓰는 점검을 '검사 못 함'으로 두라고 한다. 사용자가 두 번 모른다고 하면 되돌아가도 못 고치는데 '걸림'이라 상태를 못 정한다. 이번엔 '걸림(미해결)'로 적고 머리표를 '광고주 확인 대기'로 넘겼다. 미해결 걸림의 상태 규칙이 필요하다.
2. **카드 1-가 "그것만 다시 묻는다"** — 금액 기준만 단독 차례로 물었더니 한 차례가 늘었다. 다음 카드 질문 맨 앞에 붙여도 되는지 정해 두면 좋겠다.
3. **진행 중인 달(10월 잠정) 처리 규칙이 없다**(카드 1-나 판정). 네이버 머리글에 '10/26까지 실적 + 예약분'이 있어 잠정으로 썼는데, 메타 · 카카오도 같은 기준인지는 알 수 없었다. 진단을 8→9월로도 확인하는 규칙을 문서화하면 좋겠다.
4. **screen-guide 키워드 도구 열 이름.** 스킬은 '월평균 클릭수'를 받는다는데, 캡처4에는 '월평균클릭률'만 있었다. 브랜드 키워드 줄은 '검사 못 함', 일반은 검색량 × 클릭률 식으로 갔다. 도구 열 이름(클릭수 / 클릭률)을 구분해 안내해야 한다.
5. **카탈로그 판정 지표 vs 합계 ROAS.** 파워링크 · 카카오 리타겟은 판정 지표에 ROAS가 없어 줄 ROAS를 못 쓴다. 그런데 합계 ROAS는 매출이 필요해서 '구매 합 × 객단가'로 계산했다. 이 방식을 카드 7에 적어 두면 좋겠다.
6. **★ 가설 표시 폭증.** 오름세 추세를 반영하면 단가 · 전환율 끝값이 거의 다 기록 범위 밖이 되어 ★가 전 줄에 붙는다. '추세 반영 끝값'과 '증액으로 기록을 넘는 값'을 구분하는 규칙이 필요하다(오류 8 ③).
7. **구매 측정 판정.** "이벤트 관리자 권한 없음 · 광고 관리자에 구매 숫자는 나옴"을 '확인됨'으로 볼지 '확인 못 함'으로 볼지 판정표에 없다. 보수적으로 '확인 못 함'으로 했다.
8. **전환값 고정 의심.** 네이버 · 메타 전 줄 · 전 달 전환 1건당 매출이 4.5만 원으로 같았다(고정 전환값 가능성). 스킬에 이 점검이 없어 판정 줄 참고로만 적었다.
9. **예산 단위.** "1,200이요"의 단위를 묻는 칸이 없다. 지난 석 달 합(1,180~1,200만 원)으로 만 원 단위라 확인했지만, 카드 1-가에 단위 확인이 있으면 좋겠다.
10. **ROAS 300 해석**(300% = 3.0배)과 매출 기준(자사몰 / 매체 보고)을 카드 1-가에서 같이 확인하지 못했다. 5칸에 '확인 전'으로 적었다.
11. **✋1 · 2 합치기 조건**('진단이 지난달과 같다')은 프로필이 없으면 판정할 수 없어 합치지 못했다.
12. **카드 10 vs 시나리오 '컨펌 메시지 주세요'.** 카드 10은 컨펌 메시지를 기본으로 내므로 이미 낸 뒤였고, 마지막 차례에 다시 붙이는 것으로 처리했다.
13. **1칸 'N 확인 못 함 목록' vs 6절 '광고주용 본에 내부 칸 금지'.** 일곱 칸 1번 양식에 확인 못 함 항목이 있는데 6절은 광고주용 본에 넣지 말라고 한다. 이번엔 1칸에 '반영 안 함'만 두고 확인 못 함은 7칸으로 넘겼다.
14. **컨펌 마감 (제안) 날짜.** 오늘 날짜를 모르는 채 시작일 전 날짜(10/30)를 붙였다. 사용자가 고친다는 가정이다.
15. **학습 하한 위쪽 끝.** 구매 단가 위쪽 끝이면 하한 미달(502만 > 490만)이라 6칸에 '주간 구매 50건 미만이면 최적화 단계 올림'을 달았다(가안 11).

## 사용자 역에서 시나리오에 답이 없어 "모르겠어요"로 넘긴 것
- 목표 매출 · 전환율 목표 / 컨펌 마감일 / 금액 기준(시나리오대로) / 전환 인정 기간 설정값 / 카카오 구매 전환값
- 10월 메타 · 카카오 값의 기준일은 묻지 않고 넘어갔다(네이버만 시나리오 답이 있음) → 확인 못 함 처리
- 구글 사용 여부는 사용자에게 직접 묻지 않았다(세 매체 합 ≈ 예산이라 추론) → 확인 못 함 처리
- 브랜드검색 갱신 여부 · 월평균 클릭수는 묻지 않음

## 진행하며 지킨 것
- 사용자가 붙인 네이버 비밀번호는 받지도 쓰지도 않았고, transcript에도 값을 가렸다(원칙 10).
- 처음 한 번만 "그냥 지난달이랑 똑같이" 요청이 있었고, 이유를 말한 뒤 계속 진행했다.
- 웹 검색 · 셸 · 계산 도구는 쓰지 않았다(계산은 직접). 다른 시나리오 폴더와 results의 다른 결과는 열지 않았다.
