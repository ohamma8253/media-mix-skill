# 1판 — 2026 블랙프라이데이 제안

## 광고주용 본

**머리표**: 1판 · 광고주 확인 대기(운영 기간 역제안·배분 검토 필요)

**방향 두 장**: 해당 없음 — 한 달 계획

### 계획안 — 11/24~27 (제안)

1. **진단·유형·총액·일정·조건**: 블프 매출 규모 키우기(가설), 여성 아우터 발견형. 1,000만 원 매체비(부가세·수수료 별도). 하루 요청에 4일 연속 운영, 11/27 집중을 역제안. 11/25 인플루언서 영상 공개. 구매 이벤트 정상 확인; 자체 객단가·전환율·과거 성과 미확인.
2. **기간별 금액**: 4일 총액 1,000만 원 제안. 네이버 브랜드검색 7일 견적 25만 원. 나머지 배분은 키워드 수요와 학습 가능 금액 확인 후 확정.
3. **매체·상품**: 브랜드검색(25만 원 견적); 메타 판매 캠페인(신규·리타겟 통합 검토); 네이버 파워링크는 검색 한도 확인 후. 역할별 금액 미확정.
4. **매체 안 구성**: 11/25 영상 공개에 맞춰 신규 유입을 준비하고 11/27 행사에 판매 목적 집행을 집중하는 방향. 세팅은 다음 단계.
5. **예상 수치·성과 기준·목표 대비**: 카페24 매출, 달력 기준. 메타 계정 설정 클릭 7일·조회 1일. 목표 ROAS 400%. 비슷한 패션 광고주 경험 범위는 누비결 예측이 아닌 가설. 객단가 9만 원 가정이면 목표 구매 단가 22,500원, 목표 매출 4,000만 원, 약 445건이 필요(목표 역산).
6. **변경·판정·일정**: 하루 집행 대신 연속 4일 운영 역제안. 카페24 매출로 판정. 11/18까지 일정·예산 컨펌. 행사 전후 성과 점검.
7. **광고주에게 받을 것**: 행사 할인가 객단가, 일반 키워드 검색량·월평균 클릭수·클릭 단가, 11/27 전후 일정 승인.

**컨펌 메시지 초안**: 블랙프라이데이 매출 목표를 위해 11/25 영상 공개와 11/27 행사를 연결한 4일 운영을 제안드립니다. 하루 집행은 최적화 데이터를 모으기 어려워 마지막 행사일에 집중하는 방식입니다. 매체비 1,000만 원이며 부가세·대행 수수료는 별도입니다. 네이버 브랜드검색 견적 25만 원을 반영했고, 나머지 금액은 검색량·학습 가능액 확인 후 확정하겠습니다. 성과는 카페24 매출로 판정합니다. 11/18까지 일정과 객단가 자료를 부탁드립니다.

**자료 요청 초안**: 11/18까지 행사 할인가 기준 객단가, 네이버 일반 검색어·브랜드명 월 검색량과 월평균 클릭수·클릭 단가, 가능하면 기존 광고 리포트 1건을 부탁드립니다. 행사 브리프는 확인했습니다.
