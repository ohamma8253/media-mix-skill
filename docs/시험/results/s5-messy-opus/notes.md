# notes — s5-messy · opus

## 스킬을 따르며 헷갈린 곳 · 막힌 곳 · 고칠 곳

1. **카드 0 · 처음 말의 입구 단서**: "지난달이랑 비슷하게요"는 상시를 강하게 가리키지만 명시는 아니다. '처음 말에 이미 있는 것은 묻지 않는다'를 적용할지 애매해 질문 1을 그대로 물었다. → '입구를 가리키는 단서만 있으면 (잠정)으로 두고 질문 1은 확인형으로' 같은 한 줄이 있으면 좋겠다.
2. **카드 1-가 · 되묻기 차례 모양**: 금액 기준 되묻기('다음 차례에 그것만')와 1,200 단위 되묻기('다음 차례 맨 앞에 그것만 한 번')가 둘 다 '다음 차례'를 쓴다. 두 개를 한 차례에 묻고 1-나는 그다음 차례로 넘겼다. 되묻기 차례에 다음 카드 질문을 같이 붙여도 되는지(질문 3개 안이면) 정해 두면 좋겠다. 또 단위는 지난 기록이 오기 전이라 물었는데, 1-나 뒤에 합으로 맞춰 볼 수 있었으니 '지난 기록을 받을 예정이면 그 뒤에 견줘 보고, 그래도 모를 때만 묻는다'가 질문을 하나 줄인다.
3. **원칙 10 · 비밀번호**: 사용자가 비밀번호를 붙여 넣었다. 스킬은 쓰지 않는다고 알리고 바꾸라고 권하는 것까지만 있고, 대화 기록 · 산출물에서 지우는 처리는 없다. transcript에서는 가렸다. → 웹 대화에서는 지울 수 없으니 '되풀이해 적지 않는다'를 명시하면 좋겠다.
4. **카드 1-나 · 잘못 온 캡처**: '기간 · 매체 · 열이 요청과 같은지 본다'는 규칙 덕분에 메타 최근 30일 캡처를 짚고 다시 받았다. 다시 받을 때 무엇을 묻는지(매체별 · 월별 + 화면 위치)는 스킬에 없어 직접 만들었다. screen-guide에 '메타 월별 나누기 위치(분석 › 기간 나누기 › 월)' 같은 한 줄이 있으면 좋겠다(메뉴 이름은 확인 전).
5. **카드 1-나 · 손 입력 숫자 이상**: '하위 합이 위 합과 크게 어긋나면 그 줄만 다시 확인'은 있으나, 이번 오류(카카오 10월 0 하나 더)는 하위 · 위 합이 아니라 '클릭 단가가 다른 달의 10배' · '월 합이 예산과 안 맞음'으로 잡혔다. → 1-나 판정에 '같은 줄의 달끼리 단가가 몇 배로 튀면 그 칸만 다시 확인'을 더하면 좋겠다.
6. **진행 중인 달 · 매체마다 다른 집계 일수**: 네이버 캡처는 '10/26까지 실적 + 예약분'이라 적혀 있으나, 메타 월별 캡처는 기간 8/1~10/31로만 적혀 있고 첫 캡처(최근 30일 9/27~10/26, 465만 원)와 견주면 10월 480만 원이 26일치인지 애매하다. 규칙대로 10월 전체를 잠정으로 두었다. 매체마다 일수가 다를 때 진행 줄 · 입력 카드에 어떻게 적을지 규칙이 없다.
7. **객단가 출처**: 카페24 값을 못 받아 매체 보고 전환값 ÷ 구매(45,000원)로 썼다. 카카오는 전환값 열이 없어 '합계 계산용 매출 = 구매 수 × 객단가'에 이 45,000원을 넣었다. 객단가를 어디서 가져올지(자사몰 / 매체 보고 / 다른 매체 값) 순서가 스킬에 없다. 또 모든 줄 · 모든 달이 정확히 45,000원이라 전환값이 고정값으로 잡히는 것 같다. 측정 점검에 '전환값이 한 숫자로 고정됐나'를 보는 칸이 없다.
8. **카드 5 · 파워링크 + 쇼핑검색 공유 한도(가안)와 진단의 충돌**: 키워드 도구 캡처는 연관 검색어 다섯 개(월평균 클릭 합 6,523회)뿐인데, 지난 3개월 실제 파워링크_일반 + 쇼핑검색 클릭은 7,600~8,400회였다. 공유 규칙을 그대로 쓰면 지난달 금액이 한도를 넘어 90만 원을 신규 유입으로 옮겨야 한다. 진단 '단가 상승'은 역할 비중을 두라는 쪽이라 충돌했다. 한도 식을 따랐고 판단 차이로 넘겼다. 결과 박스도 이 때문에 검색 전환형이 아니라 혼합형이 됐다(10월 배분이면 검색 53.8%로 검색 전환형). → (a) 키워드 도구 값이 계정 등록 키워드 전체가 아닐 때 지난 실적 클릭이 더 크면 어느 쪽을 한도로 볼지 (b) 쇼핑검색이 파워링크와 같은 클릭 수를 나눠 쓴다는 가정이 맞는지 — 확인 필요.
9. **카드 1-다 · 클릭 단가 질문**: 질문 3 괄호의 '클릭 단가 예상값이 보이면 함께'를 물은 것으로 보고 사용자가 단가를 쳐 줬다(시나리오는 '따로 물으면'). 키워드 도구 캡처에는 단가 열이 없었다. 지난 기록 단가(805 · 335원)와 사용자 값(800 · 350원)이 달라, 한도 식에는 키워드 도구 쪽(사용자 값), 예상 수치에는 둘을 범위 양 끝으로 썼다. 한도 식에서 어느 단가를 먼저 쓸지 정해 두면 좋겠다.
10. **제품 유형 확인 문구**: '목적형 / 발견형'은 신입에게 낯선 말이라 질문에 뜻을 한 줄씩 붙였다. ✋ 1 질문 2 양식에 뜻풀이를 기본으로 넣으면 좋겠다.
11. **✋ 1 · "지난달이랑 똑같이"**: 판단을 떠넘기는 답이 왔을 때 대응 규칙이 없다. 이유 셋을 말하고 '지난달 대비'를 줄마다 보이겠다고 한 뒤 질문 1을 다시 물었다. 마케터 요청이니 역제안으로는 적지 않았다(역제안은 광고주 요청용). → '마케터가 지난달 그대로를 원하면' 분기(이유 + 지난달 대비 열, 필요하면 지난달 그대로 둔 판의 예상 수치를 나란히)를 두면 좋겠다. 이번에는 6칸에 '같은 가정으로 지난달 배분 그대로면 구매 648~717건 → 이 안 663~736건'을 넣었다.
12. **원칙 2 · 첫 화면 질문 vs ✋ 1 입력 카드**: 입력 카드 표가 길어 질문이 첫 화면에 안 보인다. ✋ 1도 '길어도 되는 차례'에 넣거나, 질문을 표 위에 두는 걸 허용하면 좋겠다.
13. **카드 8 · 미해결 걸림이 있을 때 머리표 문구**: 출력 뼈대는 '상태: 내부 검토 완료'인데 규칙은 미해결 걸림이면 쓰지 말라고 한다. ✋ 3 앞 차례에 무엇을 적을지 없어 '검토 중(금액 기준 확인 전)'으로 적었다. 뼈대에 이 경우의 문구를 넣으면 좋겠다.
14. **카드 9 · 오류 3에서 네이버 · 카카오 줄**: 카탈로그 하한이 '공식 기준 없음' · '모수가 한계'이고 대행사 권장도 없어 '검사 못 함'이 네 줄 나왔다. 상시 광고주에서 매번 같은 '검사 못 함'이 남으니, 검색 · 리타겟 줄은 오류 3 대신 오류 5로 본다고 적어 두면 깔끔하겠다.
15. **8-1 숫자 순서**: 같은 매체 · 같은 과금 안에 트래픽 / 신규 / 리타겟으로 나뉜 줄이 없으면 늘 건너뜀이다. 네이버 파워링크 브랜드(전환율 7%) vs 일반(2.9%)처럼 검색 안 축 비교는 규칙에 없다.
16. **✋ 3 질문 vs 시나리오 질문**: 사용자가 "광고주한테 그대로 보내도 돼요?"라고 물었다. 스킬에는 광고주용 / 내부본 구분은 있지만 이 질문에 답하는 문구는 없다. 광고주용 본 + 메시지만 보내고 내부본은 빼라고 답했다.
17. **카드 10 · 데이터 요청 메시지의 '양식 첨부'**: '프로모션 양식을 첨부한다고 적는다'인데 양식 자체는 스킬에 없다. 마케터가 첨부할 양식 파일이 없으면 메시지 문구만 남는다.
18. **계산 요약 뒤 '계속'**: 시나리오에 이 차례 답이 없어 사용자 말을 '계속요.'로 적었다(스킬이 '없으면 계속이라고 해 주세요'라고 했기 때문). 지어낸 답이라 아래에도 적는다.

## 사용자 역에서 시나리오에 답이 없어 "모르겠어요"로 넘긴 것 · 덧붙인 것
- 1-가 질문 1 괄호: 목표 ROAS 매출 기준(자사몰 / 매체 보고) · 구매 전환율과 분모 → "모르겠어요"
- 1-가 되묻기 질문 2: "1,200은 11월 한 달 총 1,200만 원인가요?" → 시나리오에 없음 → "그건 모르겠어요. 그냥 1,200이요."
- 1-나 질문 1 괄호: 전환 인정 기간 → "모르겠어요"(시나리오 값). 리타겟 월 노출 빈도 → 답하지 않음(모수 질문에 "그런 건 어디서 봐요?"로 함께 넘김)
- 다시 받기 차례 질문 1 괄호: 메타 · 카카오 10월이 며칠까지 값인지 → 시나리오에 없음, 답하지 않음
- 카드 0 질문 1 괄호(프로필 붙이기): "사수가 남긴 프로필은 없어요" — 시나리오의 '사수가 남긴 광고주 프로필은 없다'에서 옮김
- 카카오 손 입력 앞의 "캡처를 못 찾아서 칠게요" — 시나리오 '카카오 관리자는 캡처를 못 찾는다'에서 옮김
- 계산 요약 뒤 "계속요." — 시나리오에 없는 차례(18번)
