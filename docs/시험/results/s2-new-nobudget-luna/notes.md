# 시험 메모

- 카드 3의 총액 공식은 예산 없음일 때 목표 주문 수×예상 구매 단가라고 설명하지만, 목표 ROAS로 역산한 예산과 실제 객단가 기반 주문 수 계산이 서로 다른 금액을 낼 수 있다. 본 시나리오에서는 목표 ROAS 300%를 광고주가 명시했으므로 20,000,000÷3을 기본 총액으로 삼고, 유사 CPA 결과는 목표 미달 위험으로 표시했다. 우선순위 규칙이 더 명시적이면 좋다.
- 카드 1-다에서 일반 키워드 값을 다시 물으면 “모르겠어요”지만 이번 대화는 브랜드 수치와 제품 유형까지 한 번에 받았으므로 추가 재질문 없이 모름으로 이관했다.
- 유사 광고주 CPA를 구매 단가 범위로 추정했지만 같은 상품이라고 명시되지는 않았다. 스킬의 근거 순서는 ‘비슷한 광고주(같은 상품)’로 한정되어 있어 메타와 네이버 수치를 그대로 예측에 쓰는 것은 엄밀히 맞지 않는다. 본 결과에 ‘같은 상품 아님’과 가설을 표시했으며, 더 보수적으로는 AI 추정으로 분류하거나 사용하지 않아야 한다.
- 브랜드 키워드의 120회 클릭과 4~7% 전환율은 유사 리빙 광고주 값이다. 검색량 한도 계산에는 직접 받은 클릭수·CPC만 쓰고, 구매 예측에는 가설 꼬리표가 필요하다.
- 광고주가 계획안에 “좋아요”라고 했으므로 상태는 광고주 확인 대기. 실제 광고주 합의로 간주하지 않았다.
- 시나리오 답 중 미응답(‘모르겠어요’)은 실제 객단가, 전환 인정 설정, 리타겟 모수, 일반 키워드 수요, 구매 이벤트 화면이다. 각각 입력 카드·7칸에 전달했다.
