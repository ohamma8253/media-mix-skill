## 설계 미정에 걸린 것 (스킬 실패로 세지 않음)
- **#12 구간 시즌 배수 1.2 / 예열 정의**: 사용자는 "1/8~1/17쯤 평시의 1.2배"라고 답했고, 스킬 문턱(매출 1.5배 · 데이터랩 연평균 1.3배)에 못 미쳐 평시로 두었다. 예열은 업로드일 1/17 선증액 규칙으로 1/15~1/17 3일에 두었다. 기대 예시(평시 1/1~7 · 예열 1/8~17 × 1.2)와 달라 평시 14일 / 예열 3일이다. 본 행사 날짜와 박스에는 영향이 없다.
- **#6 클릭 단가 끝값**: 클릭 합 확인에 낮은 쪽 단가(많이 클릭)를 보수적으로 썼고, 브랜드 키워드는 범위로 보였다. 범위 안이라 인정한다.
- **#7 리타겟 월 노출 빈도 8**: 12월은 모르고(검사 못 함), 1월은 물어서 8을 받았다. 그런데 모수(4.5만 = 메타 방문자)와 카카오 줄이 매체가 달라 계산에 쓰이지 않았다(한도 '부분'의 ④). 시나리오와 스킬 양쪽이 모호한 곳이다.
- **#8 리타겟 노출 단가**: 3,000~3,500원 범위로 역산했다. 기대 쪽 2,500원과 달라도 감점하지 않는다.
- **#9 하한 표기**: 구매 단가 가운데 값을 AI 추정 2.7~6.5만의 평균 4.6만으로 써서 1,019가 나왔다(기대 868은 4.05만). 규칙(가운데 값 × 50 × 주 수)은 지켰다.
- **#13 / 시험 쪽**: 12월 한도 기대치(일반 + 쇼핑 234~312)는 금액 합 식이다. 현재 스킬은 클릭 합 식이고 쇼핑검색 클릭 단가는 12월 시나리오에 없다. 그래서 쇼핑검색 쪽 '검사 못 함'이 스킬에 맞다.

## 스킬에서 고칠 곳(이 회차 증거, 카드 번호)
notes.md에서 맞다고 확인한 것:
- **카드 0 / 사전 심의**: 질문 셋에 심의 질문이 없어 ✋ 1 괄호로 물었다. 업종으로 짐작만 하라는 규칙과 의료기기 경계 제품이 부딪힌다(transcript 36행, 149행). 카드 0 질문 2 괄호에 "의료기기 허가 여부"를 넣을지 정할 것.
- **카드 1-가 / 오늘 날짜 · 7칸 기한**: 오늘 날짜를 짐작하지 말라는데 '언제까지'에 기준이 필요했다(11/25를 "(제안)"으로 둠). 오늘 날짜를 한 줄로 묻거나 컨펌일 기준 상대 기한을 쓰라는 규칙이 필요하다.
- **카드 1-다 / 제품 유형 vs 신제품 알리기**: product-type 2절 6번(처음엔 발견형)과 진단 '신제품 알리기'의 덧씌움이 부딪힌다. 사용자가 목적형이라 답한 경우를 1칸에 어떻게 적는지 product-type 4절에 한 줄이 필요하다(transcript 154~159행).
- **카드 5 / 쇼핑검색 클릭 단가**: 한도는 '검사 못 함'이고 예상 수치는 AI 추정을 쓴다. 두 줄이 같은 값을 다르게 다룬다고 명시할 것(transcript 205행 vs 304행). **가운데 값 정의**(산술평균인지, 비대칭 범위에서 기하평균인지)와 **범위의 어느 끝으로 비교하는지**도 정해야 한다.
- **카드 4 / 카카오 모수 "합침"**: 모수를 모르면 합친다는 규칙이 매체가 다른 카카오 줄에는 맞지 않는다.
- **카드 7 / 장바구니 최적화 줄의 예상 구매 수**, **카드 9 / 8-1의 비슷한 광고주 값 포함 여부**, **카드 1-나 / 소형 가전 같은 '비슷하지만 같은 상품 아님'의 근거 순서 위치**.
- **카드 1-가~1-다 상시 · 프로필 분기**: "1번은 바뀐 것으로 대신…" 문장이 읽기 어렵다. 1-가와 1-나를 합치는 분기를 허용할 것. 12월이 진행 중일 때(끝난 달이 없을 때)의 진단 문구, 결과 박스 구간 비중에서 월 단위 고정분을 분모에 넣을지, 방향표를 '지난 계획'으로 쓸 때 몇 % 벗어나면 이유를 적는지도 빠져 있다.

채점하며 찾은 것:
- **카드 5 / 리타겟 한도의 모수 귀속**: 메타 30일 방문자 4.5만과 월 노출 빈도 8이 다 있어도 카카오 줄에 못 쓰고 '검사 못 함'이 되었다. 스킬이 다른 매체 모수를 가정으로 쓸 수 있는지(가정 표시 조건), 한 달 안 구간 합을 월 한도와 어떻게 대는지 한 줄이 필요하다. 이번 회차 '한도 부분'의 원인이다. 시나리오 쪽도 4.5만이 어느 매체 모수인지 모호하다.
- **카드 8 / 브랜드 키워드의 구간별 한도**: 월 한도만 보였다. 행사 구간(시즌 배수 적용)을 구간마다 확인하도록 계산 요약 표(상품 · 금액 · 하한 · 한도 · 판정)에 구간 열을 요구할지 정할 것.
- **카드 10 / 내부본 산출물 2**: 둘째 달 이후에는 갱신 카드를 본문에 다시 싣지 않고 포인터로 대신했다. 매번 싣는지 정해 둘 것.
- 시험 쪽: 사용자 역이 질문에 없는 값(객단가)을 가격에서 유도해 답했다. `PROMPT_web`의 "시나리오에 없으면 모르겠어요" 규칙을 다시 강조한다. 시나리오에는 4.5만이 어느 매체 모수인지와 구간별 시즌 배수(1.2)의 기준(평시 대비 vs 연평균)을 명확히 한다. 12월 한도 기대표는 현재 스킬의 클릭 합 식에 맞춰 고친다.
