# notes — s4-new-launch (sonnet, 웹 대화판)

진행: 12월 판(장기 첫 달) 전 카드 → 카드 10까지, 이어서 "12/22예요…" 1월 판(상시 입구)까지. 사용자 역은 시나리오 값만 썼고 웹 검색 · 계산 도구는 쓰지 않았다(계산은 직접). 결과 파일은 조각을 써서 `cat`으로 이었다(대화 내용 계산 아님, 파일 조립만).

## 헷갈린 곳 · 막힌 곳 · 고칠 곳 (카드 번호)
1. **카드 0 / 사전 심의**: 카드 0은 업종으로 짐작만 하라는데 질문 셋 안에 심의 질문이 없다. 의료기기 경계 제품(목 마사지기)은 짐작만으로는 부족해 ✋ 1 질문 1번 괄호로 물었다. → 카드 0 질문 2 괄호에 "의료기기 허가 여부"를 넣을지 정할 것.
2. **오늘 날짜**: 스킬은 오늘 날짜를 짐작하지 말라고 하는데, 7칸 '언제까지'를 정하려면 기준이 필요했다. 컨펌 11/18과 집행 시작 12/1 사이에서 '(제안)'으로 잡았다. 카드 1-가에서 "오늘 날짜"를 한 줄로 묻거나 컨펌일 기준 상대 기한을 쓰라는 규칙이 있으면 좋겠다.
3. **카드 1-다 / 제품 유형 짐작 vs 신제품**: 가전 분류는 목적형인데 product-type 2절 6번(처음 나왔을 때는 발견형)과 judgment 진단 '신제품 알리기'가 부딪친다. 짐작을 '경계'로 보여 줬고 사용자가 '목적형'이라 답해 목적형 + 진단 덧씌움으로 정리했다. → "사용자가 목적형이라 답했는데 진단이 덧씌울 때 1칸에 어떻게 적나"를 product-type 4절에 한 줄 추가하면 좋다.
4. **카드 5 / 쇼핑검색 클릭 단가**: 카드 5는 쇼핑검색 클릭 단가가 없으면 그 줄 '검사 못 함'이라는데, 카드 7 예상 수치에는 단가가 필요하다. AI 추정(가설)으로 넣고 한도만 검사 못 함으로 두었다. 자사몰이 네이버 쇼핑에 등록돼 있는지(소재 필수)도 확인 전이었다. → 두 줄(한도 vs 예상 수치)이 같은 값을 다르게 다루는 점 명시 필요.
5. **카드 5 / '가운데 값' 정의**: 구매 단가 범위의 가운데를 산술평균으로 썼다(4.6만, 3.1만). 범위가 비대칭일 때(2.7~6.5)는 기하평균과 차이가 크다. 정의를 정할 것.
6. **카드 5 / 한도 비교를 범위 어느 끝으로**: 클릭 단가가 범위(900~1,200)일 때 한도(234~312만)와 금액 비교를 하단으로 할지 상단으로 할지 정해 있지 않다. 일반 키워드는 하단, 브랜드 키워드는 '범위 안'으로 썼다(일관성 부족).
7. **카드 4 / 카카오 리타겟 "모수를 모르면 합침"**: 메타는 합칠 수 있지만 카카오 상품은 매체가 달라 합칠 곳이 없다. 모수 모름 + 소액 + 한도 검사 못 함으로 따로 둬서 7칸에 모수를 요청했다. → 카드 4 규칙이 '같은 매체 안 합침'인지 명확히.
8. **카드 7 / 장바구니 최적화 줄의 예상 구매 수**: 노출 우선으로 장바구니 최적화를 쓰는 줄의 구매 수를 어떻게 셀지 규칙이 없다. 노출당 식(노출 → 클릭 → 전환율 → 구매)을 그대로 쓰고 장바구니 수는 검산용으로만 적었다.
9. **카드 9 / 8-1 숫자 순서에서 '비슷한 광고주' 값**: 실측(지난 기록)만 비교한다고 하는데 '비슷한 광고주'(다른 광고주 실측)가 포함되는지 모호했다. 12월 판은 '건너뜀'으로 처리, 1월 판은 같은 매체 · 같은 과금 쌍이 없어 건너뜀.
10. **카드 1-나 / 비슷한 광고주 근거 유형**: 소형 가전은 '같은 상품'이 아니라 업종이 비슷한 정도다. 근거 순서 2번(같은 상품이면 인정)에 넣을지 3번으로 내릴지 정해 있지 않아 '비슷한 광고주(같은 상품 아님) → 범위 넓게 + 가설'로 적었다.
11. **상시 · 프로필 있음 분기(1-가/1-나/1-다)**: "1번은 바뀐 것으로 대신, 2번은 예산 · 기간만, 3번 대신 성과 내보내기, 1-나에서 그 줄을 뺀다"가 읽기 어려웠다. 1-나에 남는 질문이 자사몰 매출 하나뿐이라 한 차례가 비어 보였다. 1-가 + 1-나를 합치는 분기를 허용하면 좋겠다.
12. **마지막 달 진행 중(12/22)**: 시나리오가 며칠까지 값인지 답이 없어 "모르겠어요" → 12월 전체 '잠정'으로 처리(가안 규칙이 정확히 이 경우). 다만 "진단은 끝난 달끼리 쪼갠다"에서 끝난 달이 없을 때(기록 1개월 잠정)의 처리 문구가 없어 '쪼갤 수 없음 + 기록 짧음'으로 적었다.
13. **시즌 근거 문턱 기준**: 사용자가 "평시의 1.2배 / 1.7배"로 말했는데 데이터랩 문턱은 "연평균의 1.3배"다. 기준이 다르다. 그대로 쓰고 표시했다. 1.2배(문턱 미달)는 평시로 두고 검색 한도 배수도 1.0.
14. **카드 8 / 1월 방향표와 실제 편성 차이**: 장기 둘째 달에서 12월 판 방향표(검색 300~390 등)와 실제(248)가 달라졌다. 6칸 '바꾼 이유'에 적었지만, 방향표를 '지난 계획'으로 쓸 때 범위 밖을 몇 % 이상 벗어나면 이유를 적어야 하는지 기준이 없다.
15. **결과 박스(행사) 고정분**: 본 행사 구간 비중을 낼 때 월 단위 고정분(브랜드검색 상품)을 분모에 넣을지 모호. 구간 비중은 고정분 제외, 월 전체는 포함으로 둘 다 적었다.
16. **설 연휴 날짜**: 2027년 설이 2월 초일 수 있어(월력요항 확인 전) 2월 평시 판단과 기획전 이후 수요에 영향이 있다. 공휴일은 외부 요인 표시용만이라 판단 근거로 쓰지 않고 6칸 외부 요인 한 줄로만 적었다. 웹 검색을 못 쓰는 대화라 확인 전 표시.
17. **합의 완료 판정**: 사용자 말 "전략안은 11/18에 그대로 합의됐다"를 노출 우선 · 성과 기준 포함으로 읽고 '합의 완료'(마케터 전언)로 적었다. 스킬 규칙(역제안 결정이나 성과 기준 합의가 남았으면 합의 완료 금지)과 부딪히지 않는지 확인 질문을 하지 않았다(1회 읽기 가정을 명시함).
