# 시험 메모

- 대상: s2-new-nobudget. 스킬·references 8개를 읽고 1판을 끝까지 모의 진행했다. 사람에게 질문하거나 승인을 기다리지 않았다. 실제 브라우저 대화를 실행한 것이 아니라, 지침대로 스킬/사용자 역할을 분리한 웹 대화 모의 시험이다.
- 산출물: transcript.md에 질문·사용자 답·계산 요약·계획안·점검·메시지·프로필 전문을 기록했다. final.md는 최종 상태의 산출물 여덟 벌 항목을 광고주용 본/내부본 구분에 맞춰 묶었다. 판은 하나다.
- 시험 대화 안에서 웹 검색·셸·스크립트·계산 도구를 사용하지 않았다. 산술은 직접 계산해 반올림했다. 파일 읽기는 준비 단계의 셸 읽기, 기록은 apply_patch를 사용했다. 파일 입출력까지 셸 금지로 해석한다면 준비 단계는 엄격 준수와 다르므로 숨기지 않는다.
- 시작 때 사용자 제공 AGENTS 지시에 따라 작업 공간 밖 사용자 공통 정책 파일을 읽었다. PROMPT_web.md의 공간 밖 금지보다 먼저 수행한 공통 정책 로딩이다. 초기 파일 목록 검색 범위가 넓어 다른 시나리오 파일명도 출력되었으나 다른 시나리오 내용·업로드·다른 results는 읽지 않았다. 후속 시험은 최초부터 허용된 세 경로만 목록/읽기 대상으로 제한해야 한다.
- 업로드 차례가 없어 자료 파일·캡처는 읽지 않았다. 가상 사이트 방문, 광고 계정 조회·변경, 메시지 발송은 하지 않았다. 스킬·시나리오는 수정하지 않았다.

## 시나리오에 답이 없어 ‘모르겠어요’로 처리한 물음

- 카드 1-나: 리타겟 광고 월 노출 빈도 — 시나리오에는 최근 30일 방문자 모름만 있고 빈도 값이 없음.
- 카드 1-나: 네이버 전환추적 구매 확인 — 메타 픽셀 설치 전언만 있으므로 네이버 확인값은 모름.
- 카드 1-다 보완: 수수료율/정액 수수료/적용 기준 — 포함 여부만 있고 세부 금액 없음.
- 카드 1-다 보완: 목표 매출 및 상품 판매가의 부가세 포함 여부 — 광고비 부가세 별도 조건만 있고 매출 기준은 없음.

일반 키워드는 ‘브랜드명만 봤어요’ 답을 받은 뒤 다시 묻지 않았다. 실제 객단가 모름·전환 인정 기간 모름·온결 구매율 모름은 시나리오에 명시된 답이므로 지어낸 모름이 아니다. 계산 요약 뒤 ‘계속’ 답을 만들지 않고 목표 동시 달성 불가 설명에 대응하는 시나리오 답 ‘알겠어요. 그대로 적어 주세요’를 사용했다.

## 직접 검토한 핵심

- 🔒 실제 객단가는 1-나 괄호 질문 뒤에만, 🔒 컨펌 마감은 1-가 괄호 질문 뒤에만 공개했다.
- 오늘 날짜·문의일은 물어보지 않아 운영 판단 근거로 쓰지 않았다. 새 광고주를 신제품 출시로 바꾸지 않았다.
- 12월이라고 행사를 만들지 않았다. 1.1배<1.3배로 평시, 시즌 배수를 구매율에 곱하지 않았다.
- 브랜드 월 400회로 정액 브랜드검색 제외. 월평균 클릭수 120회로 한도 계산. 일반 검색·리타겟 모수는 추정값으로 채우지 않았다.
- 매체비 합계 1,097만+3만=1,100만 원, 수수료 합 F_M+F_N=F. 기간은 7일 블록 네 개와 3일로 31일. 실제 총 견적은 F 확인 후 확정한다.
- 메타 구매 단가 약 15,385~28,409원, 중간 학습 하한 약 485만 원·상단 약 629만 원으로 계산 가정상 충분하다. 실제 학습 완료는 미검증이다.
- 매체 보고 참고 합계 ROAS는 가장 유리한 동일 세금 기준·수수료 제외에서도 약 141.7~262.3%로 300% 미달이다. 카페24 전체 매출·ROAS 전망은 근거 부족으로 내지 않았다.
- 최종 상태는 광고주 확인 대기. 마케터의 ‘좋아요’를 광고주의 예산·목표 합의로 바꾸지 않았다.

DONE은 시험 실행과 결과 기록의 완료를 뜻하며, 광고주 계획의 확정이나 미해결 입력의 해소를 뜻하지 않는다.
