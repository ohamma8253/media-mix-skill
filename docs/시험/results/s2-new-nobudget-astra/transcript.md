**총액과 기간**

- 임시 목표 주문 수 = 2,000만÷4만 = 500건. 매출과 객단가의 부가세 기준이 같다는 조건이며 실제 확인 전입니다.
- 유사 메타 판매 구매 단가 = 노출 단가÷(1,000×클릭률×구매율) = 6,000÷(1,000×0.013×0.03)~7,500÷(1,000×0.011×0.024) ≈ 15,385~28,409원. 수수료 제외 중간값입니다.
- 기본 제안 총액 범위 = 500×위 단가 + 해당 수수료 = 약 769만~1,420만 원 + 해당 수수료. 범위 양끝 수수료는 각각 견적에 따라 달라집니다.
- 기준안 = 매체비 1,100만 원 + 수수료 F원, 부가세 별도·수수료 포함. 단가 범위 중간으로 역산한 매체비 약 1,095만 원을 반올림한 작업안입니다. F는 0이 아닌 미확인 변수입니다.
