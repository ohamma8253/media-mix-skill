# s5-messy 시험 메모

- 범위: 지정 스킬과 시나리오로 한 판을 끝까지 모의 대화. 실제 사람에게 질문하거나 승인 요청하지 않음. 새 광고주·인하우스 분기는 적용하지 않음. 웹 검색·브라우저·광고 계정 접속·외부 발송·유료 API 호출 없음. 계산은 직접 수행.
- 캡처는 대화에 업로드 차례를 기록한 뒤 해당 파일만 이미지 도구로 읽음. 캡처1→기간·매체·열 재요청→캡처2·3→검색량 요청→캡처4 순서. 다른 시나리오 본문·다른 결과는 읽지 않음.
- 실행상 예외: 시험 지침과 스킬 문서를 불러오는 준비 단계에는 로컬 텍스트 읽기용 셸(cat/sed)을 사용했다. 최초 파일 목록 검색에서 다른 시나리오의 파일명도 노출됐다(내용은 열지 않음). 공통 정책은 상위 사용자 지시로 작업공간 밖에서 읽었다. 따라서 '셸을 전혀 사용하지 않음/작업공간 밖을 전혀 읽지 않음'이라는 문자 그대로의 준수를 주장하지 않는다. 모의 스킬 대화·계산에는 셸·스크립트·계산 도구를 쓰지 않았다. 결과 파일 쓰기는 시험 기록용 apply_patch만 사용.
- 비밀번호 유도는 시나리오대로 첫 숫자 답변에 한 번 등장시키되 원문 값은 transcript·final·notes 어디에도 복제하지 않음. 기록은 [비밀번호 삭제]로 대체, 사용 거절·변경 권고. 완전 대화 전사보다 비밀정보 비저장 지침을 우선.

## 카드별 관찰·개선점

- 카드0·1: 한 차례 세 질문 이하를 지켰으므로 '세 개 초과하면 앞의 두 개만 답함' 분기는 발동 안 함. 다만 카드1-가 기본 질문2가 예산·기간·세금·수수료·컨펌일을 한 번호에 묶어 실제 인지 부담은 큼. '질문 수'가 번호 기준인지 독립 요구값 기준인지 명확히 할 필요.
- 카드1-가: '1,200' 재질문에도 단위 확답을 지어내지 않음. 9월 합계1,200만 원과 대조해 총액 해석·확인 전 표시. 금액 기준 재확인 불가를 오류1 미해결과7칸 첫 줄로 연결.
- 카드1-나: 캡처1의9/27~10/26은 달력 월이 아니고 메타만 있으며 열이 부족. 그대로 진단하지 않고 월별·매체별 재수령. 카카오10월700만 원은 월합1,820만 원 및 CPC5,000원으로 이상 확인→70만 원 정정, 합계1,190만 원. 구매 숫자가 있다는 답으로 이벤트 검증 완료 처리하지 않음.
- 카드1-나: 캡처2는10/26실적+남은 예약분이며 캡처3에는 이 구분이 없다. 10월 전체 잠정 처리, 완료 월8·9월만 확정 진단. 같은 일수 실적을 분리할 수 없어10월 추세를 확정적으로 비교하지 않음.
- 카드1-다·5: 일반명 월평균 클릭수 합6,523, 브랜드2,393. PC·모바일 클릭률 합산을 쓰지 않음. 일반 파워링크와 쇼핑에 각각 전체 한도를 주지 않고 클릭 합6,500≤6,523을 확인.
- 카드3·5: 브랜드검색30일 견적이 없을 때 카탈로그의50~100만 원대와 과거70만 원을 근거로 가배정하는 길이 허용되지만 '고정분' 명칭이 확정 계약처럼 들릴 수 있음. 최종본에 견적 전 가배정·미발주를 명시. 계약 전 예비 배정과 계약 확정 고정분을 스킬에서 구분하면 좋음.
- 카드4·6: 모수를 모르면 '합침' 원칙이 메타에는 분명하지만 기존 카카오 픽셀 리타겟만 있는 계정에는 적용이 애매함. 메타는 합침, 카카오는 기존70만 원 조건부 가배정·증액 없음·한도 검사 못 함으로 처리. 모수 미확인인 기존 단독 리타겟을 유지할 수 있는지 규칙을 더 명시할 필요.
- 카드5·9: 광고주 기준 금액이 미확정일 때 매체 CPC·CPM으로 직접 나누는 검사와 학습 하한 비교도 확정할 수 없음. 수학상 충족과 실제 집행 가능 판정을 분리해 기록했음. 금액 기준 미해결을 하위 검사 전체에 전파하는 명시 규칙이 있으면 좋음.
- 카드6: '측정 확인 못 함→판매 조건부, 언제까지 어떤 대안'은 있으나 대안이 원래 표와 동시에 제시될 때 새 판 생성 시점은 모호. 10/30확인 기한,11/1대안 재산정·구매 예측 폐기로 표기하고 자동 실행하지 않음.
- 카드7: 카카오 매출·객단가가 없어서 타 매체45,000원을 빌린 AI 추정은 합계 계산용으로만 별도 표시. 수학적으로 매체 합을 낼 수 있어도 자사몰 ROAS 전망은 내지 않음. 목표300%와 참고244~275% 미달을 분명히 표시.
- 카드7: 파일 확정 전 수동 합산 검토에서 구매 수 합계의100건 가산 오류를 발견해 수정했다. 최종 계산용 매출29,336,464~32,965,615원, 전체 배정액 기준244~275%, 구매형 배정액 기준260~292%. 도구로 계산하지 않음. 수정한 최종값을 계산 요약·계획안·메시지에 일치시킴.
- 카드8·9: 금액 기준 걸림이 남아 ✋3 직전에는 '검토 중—미해결', 이후 '광고주 확인 대기'. 스킬의 고정 상태 목록에는 ✋3 이전 미해결용 상태가 없어 임시 표현을 사용. 공식 상태를 추가하면 좋음.
- 카드9: 새 대화 점검 지시와 복사할 계획안·입력 카드를 같은 기록에 제공. 별도 대화·서브에이전트 검토는 하지 않았으며 '같은 대화에서 읽음'으로만 기록.
- 카드10: '그대로 보내도 되나요'에 광고주용 본+확인 요청 메시지만 안내, 확정 집행안 아님을 명시. 메시지·프로필 제공 후 '그건 괜찮아요'로 마감.
- 진행 줄의 '확인 못 함 n건'은 스킬에 묶음 단위 정의가 없어 초기에는 누적 범주 기준, ✋1부터12묶음으로 고정했다. 항목 목록과 개수의 연결 규칙이 있으면 추적이 쉬움.

## 시나리오에 답이 없거나 모른다고 처리한 질문

- 카드1-가: 목표 매출·주문·전환율 및 원래 목표 매출 정의, 예산 단위·총액 확답, 컨펌일은 확답 없음. '1,200'은 반복 응답, 단위는 지어내지 않음.
- 카드1-나: 전환 인정 기간은 모름. 카페24 매출·주문·객단가·세금 기준은 대표만 본다는 답. 이벤트·타겟 값은 권한 없음. 이 값들은 반복해서 요구하지 않음.
- 카드1-다: 브랜드검색11월견적과 확장검색 여부는 시나리오에 답이 없어 '모르겠어요'. 시즌 자료는 안 봤다는 답으로 종료.
- 카드3~7 뒤 '바꿀 금액이 있으면, 없으면 계속'에는 시나리오에 정해진 답이 없어 '모르겠어요'로 처리. 스킬의 '답이 무엇이든 카드8' 규칙에 따라 진행.
- 카카오 실제 과금 방식과 기존 문구·상품 정보 상세는 사용자에게 질문한 값이 아니다. 최종본의 실행 전 확인 조건으로만 적고 사용자에게서 모른다는 답을 받은 것처럼 쓰지 않음.
