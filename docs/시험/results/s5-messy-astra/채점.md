## 설계 미정에 걸린 것
- **#2 결과 박스(혼합형 vs 검색 전환형)**: 이 회차는 혼합형 — 신규 유입 49.58%로 50% 바로 아래, 검색 44.58%로 가장 큰 몫이 아님. 이 차이는 '설계 미정'으로 두고 스킬 실패로 세지 않는다. 박스 칸은 지시대로 '부분'으로만 매겼다.
- **#6 한도 단가 끝값**: 일반 800원 · 브랜드 350원 · 쇼핑 500원(가정 범위 안), 식이 보여 인정.
- **#7 리타겟 월 노출 빈도**: 모수 · 빈도 모름 → 스킬 규칙대로 '검사 못 함'. 걸린 것 없음.
- **#10 · #13 금액 기준 · 지출 기준**: 모른다 → '확인 전' + 7칸으로 일관.
- 위 외 13건 가운데 이 회차에 걸린 것 없음(#11은 일반 키워드 줄을 넣었으나 s5는 일반 검색량을 받아 한도까지 검사했음).

## 스킬에서 고칠 곳(이 회차 증거, 카드 번호)
notes.md에서 맞다고 확인한 것:
- **카드 1-가(질문 4개 이상 규칙)**: '번호 하나 = 하나, 괄호는 안 셈' 기준으로는 3개 이하지만, 질문 2가 예산 · 기간 · 부가세 · 수수료 · 컨펌일을 한 번호에 묶어 실제로 답할 것은 5가지다. 이번 사용자는 다 답했으나 번호 기준 vs 요구값 기준을 규칙에 분명히 할 필요(낮은 우선순위, 확인 필요).
- **카드 3 · 5(브랜드검색 가배정)**: 견적이 없어 과거 계약비 70만 원을 '견적 확인 전 가배정'으로 두었는데 '고정분'이라는 이름이 확정 계약처럼 들림. 계약 전 예비 배정 vs 확정 고정분 구분 필요.
- **카드 4 · 6(모수 모르는 단독 리타겟)**: '모수 모르면 합침'은 메타에는 분명하지만 카카오 픽셀 리타겟 단독 줄을 유지해도 되는지 규칙이 비어 있어, 증액 없이 70만 원 조건부 유지로 풀었다.
- **카드 5 · 9(금액 기준 미해결의 전파)**: 부가세 · 수수료 기준이 미확정이면 클릭수 · 학습 하한 검사도 확정할 수 없는데, '수학상 충족'과 '실제 집행 가능'을 나눠 적었을 뿐 명시 규칙이 없다.
- **카드 6(측정 확인 못 함 대안)**: '10/30 확인 못 하면 11/1 목적 변경 대안 재산정'은 적었으나 새 판을 언제 만드는지 모호.
- **카드 8 · 9(✋3 전 상태)**: 입력이 없어 못 고친 걸림이 있을 때 ✋3 뒤 '광고주 확인 대기'는 정해져 있으나 ✋3 이전 상태 이름이 없어 '검토 중 — 금액 기준 미해결'을 임시로 씀.
- **진행 줄 '확인 못 함 n건'**: 묶음 단위 정의가 없어 4 → 7 → 9 → 8 → 10 → 12로 오르내림. 항목 목록과 건수의 연결 규칙 필요.

채점하며 찾은 것:
- 카드 ✋1 "지난달 똑같이" 응답은 한도 이유부터 말하고 진단은 ✋2에서 나온다(순서상 문제는 아니나, 규칙 대응 8의 '진단과 바꾸는 이유'를 ✋1에서 한 줄 미리 말하면 더 안전).

시험 쪽(스킬 실패로 세지 않음):
- **캡처4 일반 검색어 클릭 합 6,523이 지난달 파워링크 일반 + 쇼핑검색 실제 클릭 7,602(10월 3,602 + 4,000)보다 작다.** 현재 스킬의 '두 줄 클릭 합 ≤ 월평균 클릭수' 규칙을 쓰면 지난달 모양 그대로(7,625클릭)인 첫 안부터 한도에 걸려 일반 파워링크 290 → 160으로 줄고 메타가 595까지 올라 검색 44.6% · 신규 49.6%의 혼합형이 된다.
- s5-messy.md의 기대 '검색 전환형 · 검색광고 > 50%'와 한도 값 '일반 한도 약 520'(일반 한 줄 단독 계산)은 이 공유 클릭 한도 규칙 이전의 값이다. s1 1판(일반 210 + 쇼핑 250 = 2,625 + 5,000 = 7,625클릭)도 같은 규칙으로는 한도를 넘는다. s5 기대 박스와 한도 값을 규칙에 맞춰 다시 정해야 한다.
- 진단 기준의 805원(+15%)은 10월(잠정) 값을 포함한 수치다. 스킬이 잠정 월을 빼고 8→9월(+8.6%)로 진단한 것은 스킬 규칙에 맞고 방향도 같다.
- 사용자 역이 질문 밖 항목("바꿀 금액이 있으면…")에 시나리오 규칙 7번대로 "모르겠어요"로 답했다. 문제 없음. 비밀번호 값은 기록 정책상 transcript에서 삭제돼 있어 값 자체 검사는 못 했다(사용 · 권고 여부는 확인).
