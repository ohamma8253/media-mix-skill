# s3-new-event 시험 메모

## 실행 범위와 제한
- 지정 스킬 SKILL.md와 references 8종, PROMPT_web, s3 scenario만 시험 근거로 사용했다. 다른 시나리오·다른 results는 열지 않았다.
- 사람에게 질문하거나 확인받으려고 멈추지 않았다. transcript의 질문은 시나리오 사용자에게 하는 모의 질문이며 실제 사용자 입력 요청 도구를 쓰지 않았다.
- 웹 검색·브라우저·광고 계정 접근·계산기·계산 스크립트·외부 API·발송·집행은 하지 않았다. 산술은 직접 계산하고 반올림했다.
- 파일·캡처 업로드 차례가 시나리오에 없어 추가 파일은 열지 않았다. “광고주 캡처”는 사용자 설명으로만 기록했다.
- 절차상 제한: 시작 시 제공된 AGENTS 지시 때문에 작업 공간 밖 사용자 공통 정책 파일을 읽었다. 시험 지침을 처음 읽는 호출과 이후 필수 문서 로딩에는 로컬 전용 파일 읽기 도구가 없어 exec_command의 cat/sed를 사용했다. 따라서 “셸 명령을 전혀 쓰지 않음”을 실행 전체에 문자 그대로 적용하면 충족하지 못한다. 셸을 계산·조사·시뮬레이션 실행에는 쓰지 않았지만 엄격 무셸 시험으로 주장하지 않는다. 결과 기록은 apply_patch로 했다.
- 처음 경로 점검은 AGENTS 존재 확인을 포함했다. 다른 프로젝트 자료나 결과 내용은 읽지 않았다.
- 계산·텍스트 조립은 구분했다. functions에서는 이미 작성한 문자열을 저장·연결하고 파일로 기록했으며 금액 계산 로직은 실행하지 않았다.
- 독립 새 대화 점검은 실행하지 않았다. 스킬 지시대로 같은 대화에서 읽고 새 대화용 점검 문구를 제공했다.
