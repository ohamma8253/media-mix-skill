# notes — s3-new-event (sonnet)

진행: 시나리오 끝까지 완주(1판 → 광고주 답 11/14 → 2판 → 광고주 답 11/15 → 합의 완료). 웹 검색 · 계산 도구는 쓰지 않았고 숫자는 직접 계산했다. 셸은 스킬 문서 읽기와 결과 파일 조립(조각 파일 이어 붙이기)에만 썼다. 시나리오에 "[파일 올림]" 표시가 없어 파일 · 캡처는 읽지 않았다.

## 스킬에서 헷갈린 곳 · 막힌 곳 · 고칠 곳

**입력 단계**
- 카드 0 / 1-가: 웹 검색이 없을 때 업종 · 가격대를 "카드 1-가의 괄호로" 붙이라 했는데 질문 3개 안에서 어느 번호에 붙일지 정해져 있지 않다. 1-가 질문 1의 괄호에 붙였다.
- 카드 1-나(새 광고주) Q1: **객단가를 묻는 칸이 없다.** "받지 못했으면 가격대로 짐작(AI 추정) · 가격대도 모르면 ✋ 1에서 묻는다"뿐이라, 가격대(15~30만)가 있으면 묻지 않고 넘어가게 된다. 50% 할인 행사는 객단가가 ROAS를 바로 바꾸므로 Q1 괄호에 "행사 때 객단가를 아시는 만큼"을 내가 더했다(스킬 문구에 없는 추가). 고칠 곳: 새 광고주 1-나 Q1에 객단가 한 줄 추가.
- 카드 1-나(새 광고주) Q3: 전환 인정 기간 설정값을 묻는 줄이 상시 Q1에만 있다. 캡처에 보일 만한 값이라 Q3 괄호에 옮겨 적었다.
- 카드 1-다 Q3: **브랜드검색 상품 견적(가격)을 묻는 곳이 없다.** 카탈로그에는 30일 50만~100만 원대[대행사]뿐이라 7일 계약 금액을 알 수 없고 "짐작으로 채우지 않는다"와 부딪힌다. Q3 괄호에 "7일 기준 견적"을 내가 더했다. 고칠 곳: 1-다 Q3에 브랜드검색 견적 추가.
- 카드 1-다 Q3 / 카드 3 / 카드 5: **월평균 클릭수 vs 클릭률.** 사용자가 준 값은 월평균 "클릭률" 30%였고 클릭수가 아니다. 스킬 규칙대로 브랜드 키워드 줄 한도를 '검사 못 함'으로 두었는데, 한도를 못 재는 줄의 **금액을 어떻게 정하는지** 규칙이 없다(15만 / 30만은 내 재량 소액). 일반 키워드 줄은 클릭 단가 · 전환율도 없어 예상 수치를 '비움 · 합계에서 뺌'으로 처리했는데 이 처리도 규칙에 없다.
- 1-가 성과 기준 기본값 문구 "달력 월": 4~8일 행사에는 맞지 않아 5칸에서 '집행 기간 단위'로 바꿔 적었다. 기본값 문구에 짧은 행사 분기가 필요하다.
- 오늘 날짜(11/11)를 스킬이 묻지 않는다. 컨펌 마감 · 집행 시작 제안 · 7칸 기한을 정하는 데 오늘 날짜가 필요한데, 규칙은 "오늘 날짜를 짐작해 정하지 않는다"뿐이다. 이번에는 프로모션 자료 받은 날(11/10)과 컨펌 마감(11/18)으로 설계했다.

**계산 단계(카드 3~7)**
- 카드 3 "하루만 켜 달라" → "최소 2~3일 연속 + 마지막 날 증액" 역제안: 며칠로 할지 · 예열 일수 · 소재가 없는 날(영상은 11/25 업로드분이라 11/24에는 영상이 없음) 처리 규칙이 없다. 4일(11/24~27, 11/24는 이미지 소액 학습)로 정한 근거는 내 판단이다.
- 카드 5 리타겟 한도 "하루 1회 × 일수(가안)"는 기간 합만 정의한다. 하루 안에 몰리는 금액의 상한은 없어 11/27 110만 원이 통과될 뻔했다. 하루 상한(모수 × 노출 단가 ÷ 1000 = 64만)을 내가 더해 110 → 64로 고쳤다. 고칠 곳: 짧은 행사 한도에 일 상한 명시.
- 학습 하한 식의 '주 수'가 4일 · 8일일 때 소수(기간 ÷ 7)로 쓰는지 규칙이 없다. 4/7 · 8/7로 썼다. 광고세트 수(신규 2 · 리타겟 1)도 가정이다.
- 카드 7 합계 규칙 충돌: "전체 예상 매출은 카페24로만, 중복 뺄 근거 없으면 매체 합계를 쓰지 않는다"와 "목표 대비 한 줄"이 부딪힌다. 매체 보고 기준 합은 '구매형 상품 ROAS / 전체 광고비 기준 ROAS' 두 이름으로 참고 표시하고, 카페24 기준 전체 예상은 '범위 안 냄'으로 적었다.
- 파워링크 줄에 ROAS를 적으면 오류 4②(판정 지표에 없는 지표)에 걸려, 파워링크는 구매 단가만 적고 합계 계산용 매출은 중간값으로만 두었다. 이 해석이 맞는지 스킬에 예시가 필요하다.
- 브랜드 키워드 구매 전환율 3~5%는 분모를 말하지 않았다. '클릭으로 가정, 분모 미확인'으로 적었다. 분모를 모를 때 범위를 얼마나 넓힐지 규칙이 없다(넓히지 않고 표기만 함).
- 결과 박스 분모: "상품 금액 합 + 고정분"인데 구간별(본 행사 블록)로 매길 때 고정분이 어느 구간에 속하는지 모호하다. 고정분을 뺀 블록 합으로 매겼다. 앵콜 블록만 보면 혼합형이 되는데 "가장 큰 본 행사 블록으로 매긴다"에 따라 11/27 기준 신규 전환형으로 적고 참고로만 남겼다.
- 2판: 반복 행사(앵콜)에 같은 역제안(연속 + 사이 소액 유지)을 다시 적용하는 규칙은 5절 판단 규칙으로 해결됐으나, "광고주가 이미 수락한 4일 연속"과 "새 역제안(앵콜 연속)"을 6칸에 어떻게 함께 쓰는지 양식이 없다('결정됨 / 결정 부탁'으로 나눠 적음).
- 2판에서 '1,200이 총액인지' 시나리오에 답이 없어 "모르겠어요"로 넘겼다. 스킬은 "올린다"는 말대로 총액(+200)으로 가정하고 7칸으로 넘겼다. 이런 모호한 숫자를 처음 받을 때 되묻는 위치가 카드 10 '광고주 답을 받은 뒤(가안)'에 없다.

**카드 10 / 진행**
- 카드 10은 컨펌 · 요청 메시지를 먼저 "기본으로 낸" 뒤에 더 필요한 것을 묻는다. 시나리오의 "다음 작업 고르기: 컨펌 메시지랑 요청 메시지 주세요"가 이미 낸 것을 다시 달라는 말이 되어 "위에 있다"고 답했다. 2판도 같은 패턴(프로필 정리 요청).
- 합의 완료 조건: 광고주의 "이대로 좋다"가 7칸에 남은 열린 항목(ROAS 분모 등)까지 덮는지 규칙이 없다. 역제안 결정 · 성과 기준 합의만 확인하고 합의 완료로 올리되 열린 항목은 기록에 남겼다.
- 점검 [판단] 2 · 9 · 11은 모두 '같은 대화에서 읽음 — 새 대화 읽기 전'으로 적었고, 새 대화 점검 묶음을 두 판 모두 코드 블록으로 냈다. 실제로 새 대화에서 읽지는 않았다.

- 🔒 값은 스킬이 물었을 때만 꺼냈다: 컨펌 11/18(1-가 Q2 괄호) · 객단가 9만(1-나 Q1 괄호, 내가 더한 문구) · 브랜드검색 25만(1-다 Q3 괄호, 내가 더한 문구) · 성과 기준 합의(2판 Q3). 앞의 둘은 스킬 원문에 없는 괄호를 내가 더해 얻은 값이라 "스킬이 안 물어도 나오는가"의 시험으로는 쓸 수 없다.
