## 스킬에서 고칠 곳(이 회차 증거, 카드 번호)
notes.md에서 맞다고 확인한 것:
- 카드 5: 키워드 도구 캡처에 일반 검색어가 여럿일 때 합치는 규칙이 없다. 다섯 개 합(6,523)을 가정으로 쓰고 판단 차이에 올렸는데, 대표 검색어 하나(2,989)만 쓰면 일반 두 줄이 한도를 넘는다. 합치는 법(겹침 처리 포함)을 한 줄로 정해 둘 곳(notes 8번). 같은 장면에서 "실제 집행 클릭이 도구 합보다 크면 어느 쪽을 믿나"(notes 9번)와 "쇼핑검색 클릭 단가가 없을 때 지난 기록 실측치를 쓰는가"(notes 10번)도 한 줄씩.
- 카드 1-가 · 1-나: "금액 기준이 빠지면 다음 차례에 그것만 다시 묻는다"와 "한 번에 한 카드"의 충돌, 견줄 값이 곧 이어지는 카드에서 올 때 묻지 않는 경우(notes 1 · 2번). 이번 회차는 금액 기준을 한 차례에 따로 물어 질문 하나짜리 차례가 생김.
- 카드 1-나: 상시 1번 괄호가 지난 성과 · 진행 중인 달 · 인정 기간 · 모수 · 노출 빈도까지 다섯을 한 번호에 묻는다. 이번에도 사용자가 "어디서 봐요?"라고 되물었고 노출 빈도는 모수 답에 묻혀 사라짐. 화면 위치 안내 한 줄 + 괄호 줄이기(notes 3번). 진행 중인 달은 캡처 안 표기를 스킬이 먼저 읽는 단계를 적을 것(notes 4번).
- 카드 1-나 · 되읽기: 매체 수 · 달력 월 여부 · 열을 짚는 체크 목록으로 두면 더 단단하다(notes 5번). 이번엔 세 가지를 다 짚어 통과.
- 원칙 10: "붙여 넣으면"뿐이라 "제안하면"도 넣을 것(notes 6번). 이번 회차는 같은 방식으로 처리해 통과.
- 카드 2 → 8: 계산 요약 뒤 '계속' 문구(notes 7번). 사용자가 "모르겠어요"라고 해도 넘어가서 문제는 없었음.
- 카드 9 · 머리표: 입력 없는 걸림이 있을 때 상태 문구를 정해 둘 것(notes 11번). 이번에는 광고주용 본 머리표에 "✋ 3에서 '좋다'를 받으면 … '내부 검토 완료'는 건너뜁니다"라는 내부 진행 설명이 들어가 광고주용 본이 내부 말로 길어졌다.
