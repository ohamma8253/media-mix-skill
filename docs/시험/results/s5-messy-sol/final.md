### 6칸 · 바꾼 이유·시험·판정·다시 볼 날
- 기존 상품 우선이라는 요청을 따랐습니다. 클릭 비용이 오른 상황에서 검색량을 무시하고 전월 금액을 복사하지 않았습니다.
- 브랜드 한도: (499+1,894)×350원=837,550원. 브랜드 클릭률로 한도를 계산하지 않았습니다.
- 일반 수요 풀: 2,989+1,264+767+735+768=6,523클릭. 보수적으로 파워링크 2,400,000÷800=3,000클릭, 쇼핑 1,600,000÷465≈3,441클릭, 합 약6,441≤6,523. 쇼핑은 전망 단가보다 낮은 완료 월 단가로 한도를 더 엄격하게 봤습니다(가안). 관련어 중복·확장검색 상태는 확인 전입니다.
- 단가 상승은 같은 역할 안 조정이 원칙이지만, 기존 일반+쇼핑 490만 원을 이번 공동 클릭 한도로 뒷받침할 수 없어 검색 몫을 줄였습니다. 검색 감소분은 신규 유입에 돌리고 리타겟은 증액하지 않았습니다. 검색 한도라는 별도 근거에 따른 조정입니다.
- 시험 ①: 공동 검색 풀 안에서 금액 조정 → 구매 단가를 관리하면서 클릭 확보 → 11/14에 단가 범위·실제 검색 수요 안이면 유지, 초과하면 검색어 중복·단가 가정을 수정. 총액 확대는 별도 컨펌.
- 시험 ②: 메타는 합친 한 단위로 하한 확인 → 주간 구매 약50건 이상 확보 → 11/7·11/14에 점검. 첫 2주 주간 전환이 기준 미만이면 최적화 단계를 올리는 방안을 다시 제안하고 해당 단계 비용·지표로 재산출합니다(가안). 광고세트 1개는 하한 검사용 가정이며 세팅 지시가 아닙니다.
- 시험 ③: 보수적으로 확장한 예상 단가·구매율을 11/1~11/14 검증 → 측정 정상이고 구매 단가가 범위 안이면 유지, 범위 밖이면 가정과 소재·유입 원인을 다시 점검. 행동이 실행되지 않았다면 배분 효과로 해석하지 않음.
- 다시 볼 날: 요청 자료가 오면 즉시 재작성, 10/31 컨펌·측정 확인(제안), 11/2부터 데일리 점검, 11/7·11/14 위클리, 첫 2주 가설 판정 11/14(제안).
- 역제안·노출 우선·꺼 보기 시험: 해당 없음. 광고주 동의나 외부 요인 날짜를 지어내지 않았습니다. 행사 자료가 도착하면 일정과 외부 요인을 기록하고 재작성합니다.
