## 설계 미정에 걸린 것
- 13건 중 6번(검색 한도의 클릭 단가 끝값): 일반 800 · 브랜드 350을 사용자가 답한 대로 썼고, 식이 보여 인정. 스킬 실패로 세지 않음.
- 13건 중 13번(지출 기준): 이 시나리오는 오히려 '모른다'가 정답인 칸이라 걸리지 않음(확인 못 함 처리가 맞음).
- 새로 보인 충돌(13건 밖, 확인 필요): '파워링크 · 쇼핑검색이 같은 검색어면 두 줄 클릭 합 ≤ 월평균 클릭수'(가안, SKILL 카드 5 · judgment 한도 항목)를 따르면 쇼핑 클릭 단가(465~500원)가 일반(800원)보다 낮아 일반+쇼핑 한도가 금액으로 약 400만 위로 못 올라가고(전부 일반에 몰아도 522), 10월 실제 집행(일반 290 + 쇼핑 200 = 클릭 7,602)은 이 가안 식으로는 한도 초과가 된다. 반면 채점 기준 · s1 예시는 '일반 키워드+쇼핑+애드부스트 합 520'(일반 한도 520)을 쓴다. 그 결과 이 회차는 검색 몫이 46.15%로 50%를 못 넘어 혼합형이 됐다. 규칙을 지킨 결과라 박스 '부분'은 스킬 실패로 세지 않고 규칙 쪽 확인 후보로 둔다.

## 스킬에서 고칠 곳(이 회차 증거, 카드 번호)

- 카드 5 · 7: 금액 기준 '확인 못 함'일 때 하한·한도·매출 비율을 어디까지 계산하고 어디서 멈추는지 규칙이 없다. 이번에는 조건부 산식만 보이고 실제 순수 매체비가 오면 재검사로 처리(결과는 적절).
- 카드 2 · 4: '단가 상승이면 같은 역할 안에서 이동' 규칙과 '검색 한도 넘으면 신규 유입으로' 규칙이 부딪힘. 이번에는 한도를 먼저 지키고 이유를 6칸에 적음. 어느 쪽이 앞인지 한 줄 필요(위 공유 클릭 가안과 한 묶음).
- 카드 3: 기존 브랜드검색 계약이 다음 달에도 이어지는지 모를 때 고정분 처리 규칙이 없음. 이번에는 '견적 전 가정'으로 둠.
- 카드 3~7 끝 안내('바꿀 금액 없으면 계속'): 정해진 사용자 답이 없어 "모르겠어요"로 넘어감. 스킬은 답과 무관하게 카드 8로 가라고 이미 적혀 있어 동작은 맞았으나 문구가 질문처럼 읽힘.
채점하며 찾은 것
- 카드 1-나(되읽기): 캡처 윗줄 날짜(10/26)를 10/27로 잘못 읽어 거짓 '충돌'을 만들고 7칸에 요청까지 냄. 사용자가 10/26이라고 답한 뒤에도 충돌로 남김. 사용자 답과 캡처가 같으면 충돌 표시를 지우는 한 줄이 필요하거나 모델 읽기 실수(규칙 문제 아님, 반복되면 보강).

시험 쪽
- 입력 카드(내부본)에 "시나리오의 숨은 오늘 날짜는 일정 결정에 사용하지 않음"이 들어감: 시험 에이전트가 하네스 용어를 산출물에 씀. PROMPT_web에 '산출물에 시나리오 · 시험 용어를 쓰지 않는다' 추가 후보.
