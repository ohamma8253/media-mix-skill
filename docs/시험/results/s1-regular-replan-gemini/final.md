## 4. 계획안 일곱 칸 (산출물 4)

### 1칸 · 진단 · 유형 · 총액 · 일정 · 조건
- **진단**: 전환율과 객단가는 정상 유지되고 있으나, 매체 클릭 단가(CPC/CPM) 상승으로 유입량이 감소한 **단가 상승(유입 감소)** 상태입니다.
- **제품 유형**: **목적형** (반려견 사료는 소진 시 검색 후 비교 구매하는 필수 소모품, 검색광고 비중 50% 이상 중심 편성).
- **총 예산 및 금액 기준**: **1,200만 원 (부가세 별도, 대행 수수료 포함)** [선택 총액: 해당 없음 — 확정 예산]
- **일정**: 집행 기간 2026-11-01 ~ 2026-11-30 / 광고주 컨펌 마감 2026-10-30
- **조건**: 영상 소재 부재로 디스플레이/피드 이미지 중심 운영, 특정 매체 제외 조건 없음.
- **미확인 조건**: 프로모션 미정으로 평시 균등 배분 (행사 확정 시 재배분 예정).

### 4칸 · 매체 안 구성
- **네이버 브랜드검색**: 목적 = 브랜드 쿼리 점유 및 이탈 방지 / 대상 = '포근밥' 검색자 / 소재 = 라이트형 이미지 템플릿
- **네이버 파워링크(브랜드)**: 목적 = 브랜드 검색 완충 및 서브링크 연결 / 대상 = 브랜드명 키워드 / 소재 = 제품 강점 텍스트
- **네이버 파워링크(일반)**: 목적 = 목적 구매자 유입 확보 / 대상 = 강아지 사료, 눈물/알러지 사료 키워드 묶음 / 소재 = 성분 및 효능 리뷰 문구
- **네이버 쇼핑검색**: 목적 = 고효율 쇼핑 구매 전환 / 대상 = 주력 2kg/6kg 사료 카탈로그 / 소재 = 네이버 쇼핑 등록 썸네일
- **메타 판매 캠페인**: 목적 = 신규 모수 확장 및 즉각 전환 (머신러닝 최적화) / 대상 = 반려견 관심사 타겟 + 30일 방문자 유사 타겟 / 소재 = 견종별 급여 리뷰 및 기호성 강조 카드뉴스
- **카카오 픽셀 리타겟**: 목적 = 이탈자 재방문 구매 유도 / 대상 = 최근 30일 자사몰 방문자 모수 / 소재 = 재구매 혜택 안내 비즈보드 이미지
