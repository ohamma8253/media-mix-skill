# notes — s2-new-nobudget (sonnet, 웹 대화판)

## 헷갈린 곳 · 막힌 곳 · 고칠 곳
- **카드 0**: 처음 말에 입구 · 업종 · 파는 곳이 있어 질문을 1~2번으로 줄여 다시 매겼다. 브랜드 이름이 처음 말에 없는 경우의 번호 재매김 예시가 있으면 좋다.
- **카드 1-가 2번 / 금액 기준**: 예산이 '없음'일 때 묻는 금액 기준이 '광고주가 제안 총액을 받길 원하는 기준'이라는 문구가 카드에 없다(예산이 있을 때 문구뿐). 대행 수수료율은 어디서도 묻지 않아, 수수료 포함 총액에서 메타 실제 매체비를 못 가른다 → 금액 전체를 매체비로 계산하고 7칸에 넘김. 대행사 내부 값이라 카드 1-가에서 한 줄로 받는 편이 낫다.
- **카드 1-나 (새 광고주)**: 자사몰 매출의 부가세 포함 여부를 묻는 곳이 상시 2번에만 있다. 새 광고주는 '묻지 않음'으로 7칸에 넘겼다. 목표 ROAS의 매출 기준도 사용자가 답하지 않아 기본값 + '확인 전'으로 처리(시나리오에도 값 없음).
- **카드 1-다 3번**: 일반 키워드를 '물으면' 시나리오는 "브랜드명만 봤어요"다. 스킬은 한 번만 물었고 다시 묻지 않았다. 일반 키워드 값이 없으면 새 광고주 규칙(구매 의도 일반 키워드까지 채움)과 한도 '검사 못 함'이 부딪힌다. 쇼핑검색 시험 몫(70만 원 = 총액의 약 7%)을 정할 기준이 스킬에 없어 AI 판단으로 넣고 '판단 차이'로 표시했다. 크기 기준(예: 총액 몇 % 이하)이 있으면 좋다.
- **카드 3 총액 역산**: 자연 유입(광고 없이 들어오는 주문)을 구분하는 규칙이 없다. 500건 전부를 광고 몫으로 봤다(보수적). 브랜드 키워드 구매는 증분이 아니라는 문장은 스킬에 없어 내가 5칸에 덧붙였다.
- **카드 3 총액 범위와 줄 금액**: 제안 총액이 범위(770만 ~ 1,420만)일 때 상품별 금액을 어느 값으로 짜는지 규칙이 없다. 기준안(가운데)으로만 줄 금액을 냈다. 범위 양 끝일 때의 배분 규칙이 필요하다.
- **카드 7 필요 전환율**: 스킬은 '전환율이 없으면 목표 역산'인데, 이번엔 비슷한 광고주 전환율이 있어 실제 계산엔 그것을 썼다. 목표 ROAS 300%에 필요한 전환율은 '비교용'으로 별도 한 줄을 넣었다. 둘이 같이 있을 때의 표기 규칙이 없다.
- **목표 매출과 목표 ROAS가 같이 안 맞을 때**: 스킬은 '5칸에 한 줄 적기만'이다. 광고주 결정은 6칸 역제안 형식과 컨펌 메시지 '결정 부탁'으로 옮겼다(스킬이 이렇게 하라고 하진 않음). 이 경우 상태를 '합의 완료'로 못 쓴다는 것은 카드 10에 있으나 '미해결 걸림'에 넣을지는 불분명해 걸림 0건으로 두고 판단 차이 항목에 적었다. ROAS가 매출과 별개로 구매 단가로만 결정된다(광고비를 줄여도 안 오름)는 설명 문장도 스킬에 없어 내가 넣었다.
- **카드 5 한도 경계**: 브랜드 키워드 3만 = 120회 × 250원으로 정확히 경계. '≤'로 통과로 봤다. 클릭 단가가 범위(250~350)일 때 어느 끝으로 한도를 보는지 규칙이 없다(낮은 끝으로 보수적으로 봄).
- **진행 줄 '확인 못 함 n건'**: 세는 기준(물었음 모름 / 묻지 않음 / 짐작)이 없어 처음 6건, 이후 7건 + 묻지 않음 4건으로 나눠 셌다. 중간에 9건으로 잘못 쓴 곳을 고쳤다.
- **결과 박스**: 합친 메타 판매 캠페인을 신규 유입 · 판매로 세면 신규 전환형(가르는 순서 1번)이 된다. 리타겟 0%인 이유(모수 모름으로 합침)를 꼬리표로 달았다. 박스 이름 '신규 전환형'과 검색 7% 사이에 이상한 점은 없었다.
- **날짜**: 오늘 날짜를 묻지 않으므로 7칸 기한을 컨펌일(11/26)에서 역산해 11/20(금)을 '(제안)'으로 썼다. 스킬 규칙(오늘 날짜를 짐작하지 않음)은 지켰으나 7칸 기한 선택 기준이 불분명하다.
- 카드 8~10 분량이 매우 길다. 광고주용 본 / 내부본 / 점검을 한 차례에 내는 구조는 따를 수 있었으나, 웹 대화에서는 길이가 부담이다.

## 사용자 역: 시나리오에 답이 없어 '모르겠어요/기본값'으로 넘긴 질문
- 목표 ROAS의 매출 기준(자사몰 전체인가 매체 보고인가) — 사용자가 답에 넣지 않았다. 성과 기준 기본값(카페24 관리자 매출)에 "네"라고만 답함.
- 카페24 매출의 부가세 포함 여부, 대행 수수료율, 네이버 쇼핑 등록 여부 — 스킬이 묻지 않았다('묻지 않음'으로 7칸에 넘김).
- 일반 키워드 월 검색량 · 클릭 단가 — 시나리오대로 "브랜드명만 봤어요"로 답했고 다시 묻지 않음.
- 브랜드검색 상품 견적 — 스킬이 묻지 않음(월 400회라 제외).
