# 시험 메모 — s2-new-nobudget-sol

- 시험 방식: 한 에이전트가 스킬/사용자 역을 구분한 로컬 웹 대화 모의 시험이다. 실제 웹 서비스에서 모델을 실행한 시험이 아니다. 시나리오에 업로드 지시가 없어 추가 파일·캡처를 열지 않았다. 다른 시나리오·다른 결과는 읽지 않았다. 웹 검색·계산 도구·외부 API를 사용하지 않았다. 계산은 직접 했고 반올림했다.
- 도구 경계 일탈: 준비 과정에서 정책·지침·스킬·시나리오를 읽고 일부 파일명을 찾는 셸 호출을 사용했다. 따라서 PROMPT_web의 ‘셸 명령을 쓰지 않는다’를 시험 준비까지 포함해 문자 그대로 충족했다고 볼 수 없다. 대화 모의 진행·배분 계산에는 셸·스크립트·계산 도구를 쓰지 않았다. 결과 저장에는 apply_patch를 사용했다.
- 상위 사용자 지시로 작업 공간 밖 사용자 공통 정책 파일을 한 번 읽었고 상위 AGENTS 경로 존재를 확인했다. 이는 PROMPT_web의 공간 밖 읽기 제한에 대한 상위 지시 우선 적용이다. 시나리오의 광고주 판단 근거로는 쓰지 않았다.
- 카드 1-가: 컨펌 받을 날을 괄호로 명시해 질문한 뒤에만 11/26을 공개했다. 카드 1-나에서 객단가를 질문한 뒤에만 모른다는 답을 냈다.
- 카드 1-다: 일반 키워드 값은 첫 질문 때 ‘브랜드명만 봤어요’, 보충 때 ‘그건 모르겠어요’로 답했다. 보충은 이 한 번뿐이다. 이후 반복 질문하지 않았다.
- 시나리오에 없어 ‘모르겠어요’로 처리: 수수료율/금액/산식, 카페24 목표 매출·객단가의 부가세 포함 여부, 네이버 구매 전환추적 상태. 최근30일 방문자·월 빈도도 모름 처리. 사용자 답을 만들어 수수료10% 같은 수치로 채우지 않았다.
- 카드 3·원칙7: 부가세 별도·수수료 포함이라는 기준만 있고 실제 수수료 산식이 없을 때 완결된 숫자 총액을 만드는 길이 불명확하다. 순수 매체비를 확정 광고주 총액처럼 쓰지 않고 F 변수·견적 미완결·미해결 걸림으로 남겼다. 수수료를 어떻게 배분할지도 미확정이므로 네이버 별도 추가 청구 없음·메타 F는 잠정 구조라고 표시했다. 스킬에 이 경우의 공식 분기를 추가하면 좋겠다.
- 카드 3·7: 참고 메타 구매 단가 약15,385~28,409원, 목표500주문으로 필요 매체비 약769.23만~1,420.45만 원. ROAS300%의 총액 한도666.67만 원과 충돌한다. 사용자 역은 시나리오 지정 답 ‘알겠어요. 그대로 적어 주세요’로 진행했다. 목표에서 역산한 필요 전환율은 예측과 총액 근거로 재사용하지 않았다.
- 카드 4·5: 새 광고주는 일반 구매 의도 키워드까지 먼저 채우라는 규칙과 일반 수요 미확인 상황의 구체 금액 기준이 없다. 일반30만 원·클릭비500~750원·클릭 기준 구매율1~2%는 AI 가설로 표시하고 한도 검사를 통과시키지 않았다. 12/14 판정 조건을 달았다. 실제 수요값이 오면 교체할 임시 시험 배분이다.
- 카드 1-다·3: 데이터랩1.1배는1.3배 문턱 미만이므로 평시. 상단의 ‘시즌 근거 있으면 행사’ 요약보다 상세 문턱 규칙을 따랐다(가안). 브랜드검색 상품과 파워링크 브랜드 키워드를 구분했으며 월400회는 고정상품 제외에, 월평균 클릭120회는 브랜드 키워드 한도3만~4.2만 원에 사용했다. 클릭률30%를 대신 넣지 않았다.
- 카드 6: 구매 측정 확인 못 함에 대해 판매 조건부와11/26 전환 조건을 모두 적었다. 실제 미확인으로 트래픽 전환이 결정되면 구매 전망·총액·결과 박스까지 새로 계산해야 하며, 이번 시험에서 실제 전환·세팅을 수행한 것은 아니다.
- 카드 7·9: 세금 기준·계정 인정 기간·중복 제거 근거가 없어 카페24 전체 매출/ROAS 범위를 내지 않았다. 매체 보고 합은 목표 대비 산술 참고로만 명시했다. 파워링크 줄 ROAS는 제외하고 합계 계산용 매출만 따로 표시했다.
- 카드 8·9: 필수 금액 기준 자체는 받았으나 그 기준의 견적을 확정할 입력이 부족한 경우를 오류1 미해결로 보수적으로 처리했다. 카드9의 ‘검사 못 함’과 ‘걸림’ 경계에 수수료 산식 미확인 사례를 추가하면 좋겠다. 상태는 광고주 확인 대기이며 내부 검토 완료·합의 완료로 올리지 않았다.
- 카드9: 판단2·9·11은 같은 대화에서 다시 읽었다. 독립 새 대화 검토를 했다고 쓰지 않았다. 새 대화용 점검 문구와 함께 복사할 계획안·입력 카드 범위를 제공했다. 실제 독립 검토는 미실행이다.
- 진행 줄: 확인 못 함 수는 필드 단위인지 묶음 단위인지 스킬에 정의되지 않아 ✋1부터10개 묶음을 명시해 유지했다. 기록 없음/B1/B2/꺼진 항목은 따로 표시했다.
- 카드10: 메시지 두 개, 프로필, 다음 달 첫 말, 다시 볼 날, 카드별 기준 사례 기록을 자동 제공했다. 사용자는 ‘그건 괜찮아요’로 종료했다. 발송·광고 설정 변경·커밋은 하지 않았다. 파일 저장은 시험 하네스 결과 기록이며 스킬이 광고주 프로필을 외부 저장했다는 뜻이 아니다.
