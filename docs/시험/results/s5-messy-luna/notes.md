# 메모

- 입력 단계에서 예산 '1,200'의 단위가 없어 금액 배분을 진행할 수 없었다. 단위·부가세·수수료를 확인 못 함으로 남겼다.
- 시나리오 답에 없는 네이버 캡처의 세부 수치와 키워드 도구의 세부 행은 이 기록에서 숫자로 재현하지 않았다. 기간이 다른 메타 30일 합계를 월별 수치처럼 사용하지 않았다.
- 사용자가 비밀번호를 먼저 제시했다. 스킬 원칙에 따라 받거나 사용하지 않는다고 알리고 변경을 권했다.
- 카카오 10월 지출은 사용자가 스킬의 이상치 확인 뒤 700만 원에서 70만 원으로 정정했다.
- 구매 측정은 화면에 구매 숫자가 있지만 이벤트 관리자 확인 권한이 없어 확인 못 함 처리했다.
- 시나리오에는 ROAS 300의 매출 기준, 예산 단위/포함 기준, 컨펌 마감일이 없다. 이에 관한 후속 질문 답은 모두 확인 못 함이어야 한다.
- 스킬에서 언급된 `references/` 개별 문서 전문을 이 대화판 기록에 따로 인용하지 않았다. 세부 단가·상품 하한은 입력 근거 없이 만들어 넣지 않았다.
