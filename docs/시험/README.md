# 시험 기록 — media-mix 스킬 1차(10/30) · 재시험(11/3)

에이전트가 마케터 역을 맡아 다섯 시나리오로 스킬을 돌린 기록이다. 시나리오의 광고주 이름 · 숫자 · 캡처 화면은 모두 지어낸 것이다.

## 읽는 순서
1. [`스킬시험_v1.md`](스킬시험_v1.md) — 1차 보고(v1 직전 판, 6모델)
2. [`스킬시험_v1.1.md`](스킬시험_v1.1.md) — 재시험 보고(v1)
3. [`고칠곳_1회차_소넷.md`](고칠곳_1회차_소넷.md) · [`고칠곳_최종.md`](고칠곳_최종.md) — 1차에서 나온 고칠 곳(26건 · 40건), 설계에서 아직 정하지 않아 스킬 실패로 세지 않은 것 21건, 시험 방식 쪽 문제 10건. 보고 · 채점에서 'D3' · 'T5'처럼 적은 것이 이 두 목록의 번호다(D = 설계 미정, T = 시험 쪽)
4. [`준비_보고.md`](준비_보고.md) — 시나리오 · 채점 기준을 만든 과정과 설계 미정 13건

## 폴더
| 자리 | 내용 |
|---|---|
| `scenarios/<시나리오>/scenario.md` | 사용자 역이 아는 것(🔒 = 묻지 않으면 말하지 않는 값). s1은 `data/` CSV, s5는 `captures/` 그림 |
| `grading/` | 채점 공통 기준 + 시나리오별 기준 |
| `PROMPT_web.md` | 시험 에이전트에게 준 지시문 |
| `tools/` | 채점 지시(`채점_지시.md` · 덧붙임 `채점_지시_1103.md`), 채점 표 모으기(`모으기.py`), 질문 수 기계 세기(`qcount.py`) |
| `results/<회차>/` | 1차 28회차(1회차 5 + 최종 23): `transcript.md`(대화) · `final.md`(산출물) · `notes.md`(시험 에이전트 메모) · `채점.md` |
| `results_1103/<회차>/` | 재시험 30칸: 끝까지 돈 15칸은 위와 같은 파일, 못 돌린 칸은 `한도.md`(이유)나 멈춘 데까지의 조각 |
| `launched.tsv` | 띄운 회차 목록(회차 · 띄운 방법과 모델 · 띄운 때 · 닫은 때) |

## 공개하며 고친 곳
- 터미널 핸들 · 작업 번호, 사용자 이름이 든 절대 경로, 시험 작업 공간 이름, 실제 사람을 가리키는 이름 · 직위를 지웠다. 대화 기록 안에서 스킬이 그때 사람 이름으로 적던 자리도 사람 없이 고쳤다(예: '○○ 확인' → '확인 필요'). 그 밖의 대화 · 산출물 · 채점 글은 그대로다.
- 시험 에이전트가 읽었다고 적은 사용자 공통 정책 파일은 이름 · 경로를 뺐다.
- 채점용 숫자 파일 하나는 이름에 key가 들어가 열지 않고 뺐다. 이를 가리키던 곳은 '공개본에서 뺌'으로 적었다. 시나리오별 기준(`grading/<시나리오>.md`)에 같은 숫자의 요점이 있다.
- `launched.tsv`에서 터미널 핸들 열을 뺐고, '띄운 방법' 칸은 '띄우기 도구'(에이전트 띄우기 도구로 띄움) · '터미널 + CLI'(터미널을 열고 에이전트 CLI를 직접 실행)로 줄였다. 기록용이다.
- 에이전트를 띄우고 · 지켜보고 · 모아 닫던 셸 스크립트와 옛 복사본 점검 스크립트는 뺐다. 시험 때 쓴 에이전트 띄우기 도구와 개인 세션 기록 폴더에 묶여 있어 다른 환경에서 돌지 않는다. 보고 · 채점에서 이 스크립트를 가리키던 곳은 '공개본에 없음'으로 적었다. 채점 쪽 도구(채점 지시 · `모으기.py` · `qcount.py`)는 남겼다 — 저장소 안 파일만 읽는다.
- 시험 당시 스킬 판은 `results/`가 v1 직전 판(기록 속 이름 '고침 3'), `results_1103/`이 v1(기록 속 이름 '고침 4')이다. 지금 판(v2.0)과 문구가 다르다.
