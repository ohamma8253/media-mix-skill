# s4-new-launch 시험 메모

- 사용한 스킬은 이 폴더의 skill/media-mix/SKILL.md와 references뿐이다. 상위의 자동 노출 media-mix 스킬과 외부 test/results는 열지 않았다. 시나리오 내용은 scenarios/s4-new-launch/scenario.md만 사용했다.
- 웹 검색·브라우저·계산기·계산 스크립트·광고 플랫폼 실행은 사용하지 않았다. 계산은 직접 했다. 도구는 지침·시나리오 읽기와 결과 글의 조립·파일 기록에 사용했다. 엄격히 ‘셸 명령 금지’를 파일 읽기까지 포함한다고 해석하면 cat/sed/rg로 지침을 읽은 것은 형식상 예외다. 대화 안에서 마케터에게 셸 실행을 요구하거나 계산에 셸을 쓰지는 않았다.
- 초기 파일 탐색에서 다른 시나리오의 파일명이 목록에 보였으나 내용은 읽지 않았다. 공통 정책은 세션 시작 사용자 지침에 따라 지정된 사용자 공통 정책 파일을 한 번 읽었다.
- 외부 발송·광고 설정·실제 프로필 저장은 하지 않았다. 결과 폴더의 기록 파일만 작성했다. 업로드 지시가 없는 파일·캡처를 추가로 읽지 않았다.

## 질문과 사용자 역할

- 카드0에서 광고주·가격·판매처·권한을 받은 뒤에만 사용했다.
- 카드1-가에서 컨펌 날짜를 번호 질문으로 물어 11/18을 받았다. 시나리오의 잠금 값을 미리 계획에 넣지 않았다.
- 둘째 달 카드1-다에서 행사 상세 네 항목·수령일, 구간별 시즌 근거, 브랜드검색 가격을 각각 질문한 뒤 반영했다.
- 첫 달 다음 작업·메시지·프로필·선택 질문까지 끝내고 “그건 괜찮아요”를 받은 뒤에만 “12/22예요…”를 한 번 사용했다.
- 둘째 달은 카드0 상시·프로필 있음으로 이어받았다. 12월은 진행 중이고 종료일을 받지 못했으므로 잠정·끝난 달 없음으로 표시했다.
- 시나리오에 없는 답: 메타·구글 수수료율, 실제 객단가·부가세 기준, 계정 인정 기간, 장바구니 이벤트 정합성, 타 광고주 전환율 분모, 검색 문구·상품 등록·영상 사용 가능일·카카오 소재, 카카오 모수·첫 달 빈도, 12월 실적 종료일·상품별 지출·메타 인지 실적, 일반명 최신 클릭수는 모르겠어요로 처리했다.
- 계산 요약의 “계속” 안내는 시나리오에 대응 답이 없어 사용자 역에서 “모르겠어요”로 답했다. 스킬의 “답이 무엇이든 카드8” 규칙에 따라 계속했다.
- 첫 달 미확인17건, 둘째 달 카카오 빈도1건 해소·실적 누락3건·최신 일반 클릭수1건 추가로20건이다. 입력 카드·진행 줄·점검의 수를 맞췄다. 실제 없는 값을 묻지 않았는데 모른다고 답한 것으로 표시하지 않았다.

## 헷갈린 곳·개선 제안

1. 카드9 / checklist: “11줄(8-1·8-2 포함)”과 1~11 본 번호에 8-1·8-2를 더한 목록이 충돌한다. 누락 방지를 위해 13행으로 적었다. 규칙에 본 오류11개·추가 검사2개=13행이라고 명시하면 좋겠다.
2. 카드7·8: “숫자 근거를 내부본에 상세 표시”와 “광고주용5칸에 상품별 계산식·근거”가 일부 겹친다. 광고주용에는 조건·범위·실제 근거 유형 한 줄, 내부본에는 추정 입력값의 상세 출처를 두었다.
3. 카드1-가·5·7: 수수료율을 모르면 광고주 총액 그대로 짜라는 규칙과 실제 매체비로 학습·예상 수치를 계산하는 식 사이에 공백이 있다. 수수료를 짐작하지 않고 총액 기준 조건부 계산·잠정 표시로 끝냈다. 실제 매체비 확인 전 어떤 한도·하한 검사를 ‘통과’로 볼지 명시하면 좋겠다.
4. 카드1-나·7: 클릭/방문 전환율 분모 미확인 때 ‘분모 다름+범위를 넓힘’의 구체적 방법이 없다. 받은 전환율을 클릭 기준이라는 조건 아래 계산하고 무조건부 예측으로 쓰지 않았다. 방문/클릭 전환 비율 없이 넓힐 폭도 임의 확정할 수 없어 이 한계를 적었다.
5. 카드8·9: 상태·합의와 수수료·소재 미확인의 관계가 가안이다. 첫 달 검토 뒤는 광고주 확인 대기, 12/22의 명시 답 뒤는 전략 합의 완료·17건 유지, 둘째 달은 새 선택 결정 대기로 구분했다.
6. 카드8·10: 요청 기한≤컨펌 마감 원칙과 신제품 ‘출시 후2주 판매량’ 기본 요청이 충돌한다. 12/14 자료와 12/20 행사 자료는 발생 시점 때문에 11/18 이후라는 이유를 썼다.
7. 카드3·result-box: 행사 고정분50만 원을 본 행사 분모에 전액 넣는 가안을 적용했다. 본 행사950만 원 기준과 고정분 제외900만 원 기준 모두 신규 전환형이라 이름은 같았다.
8. 카드4·5: 새 광고주 검색·리타겟 우선과 신제품 노출 우선은 진단 덧씌움으로 정리했다. 12월 메타 장바구니 줄에는 구매·광고비 대비 매출을 내지 않았고 인지형으로 셌다.
9. 카드5·7: 둘째 달 메타의 받은 구매 단가3.1만 원과 노출→클릭→전환 식의 범위2.0833~4.0625만 원은 다른 요약이다. 받은 값은 참고 실적으로 남기고 하한에는 과금식 범위의 가운데 값을 사용했다. 주30건 초과를50건 달성으로 바꾸지 않았다.
10. 카드1-다·3: 예열 구간1.2배는 문턱1.3 미만이라 검색 한도 배수1로 처리했다. 예열 구간 자체는 확정 프로모션의 사전 안내 제안으로 두었다. 본 행사에만1.7배를 적용하고 전환율·구매 수에는 시즌 배수를 곱하지 않았다.
11. 카드1-라·5: 메타 방문자1만→4.5만은 카카오 모수에 쓰지 않았다. 카카오 금액은 제시하되 그 줄 한도를 검사 못 함으로 남겼다. 카카오 모수가 없는 상태의 시험 금액 규모는 판단 차이로 명시했다.
12. 카드7: 1월15% 할인은 예상 객단가에도 반영해야 한다. 같은 전환율 범위여도 상품별 본 행사 예산 비중이 달라 월 광고비 대비 매출의 할인 반영률이 달라짐을 적었다.
13. 카드10: 다음 달 첫 말에 프로필을 함께 붙이는 구조가 중복을 만든다. 본 기록은 프로필 블록과 다음 첫 말 블록을 각각 냈으며 실제로 저장했다거나 전송했다고 쓰지 않았다.

## 결과 범위

- 첫 달: 방향 두 장+12월 일곱 칸+점검+두 메시지+프로필·다음 첫 말·기준 사례+다음 뎁스 해당 없음.
- 둘째 달: 한 달 행사 일곱 칸·구간×상품 표·점검·두 메시지·갱신 프로필·다음 첫 말·기준 사례+다음 뎁스 해당 없음.
- 시나리오는 둘째 달 다음 작업에서 끝난다. 2월 계획은 임의로 시작하지 않았다.
- 도구로 수치 검산이나 외부 성과 검증을 했다는 주장은 하지 않는다. 수치는 수기 계획과 그 조건부 점검 결과다.
