# 시험 메모

- 시나리오가 요구한 “그대로 가요” 확인에는 입력 카드 확인과 제품 유형 확인을 한 응답으로 뭉쳤다. 스킬 카드상 확인 질문 두 개였으나 시뮬레이션 응답 한 차례로 기록했다.
- 첫 계획의 검색 일반 키워드 클릭 한도는 받았지만 파워링크·쇼핑검색 두 상품 간 실제 클릭수 배분을 못 받았다. 결과적으로 일반 한도 전체를 양 상품에 각각 반씩 배분하면서 각 상품의 클릭 단가 근거가 불충분했다.
- 첫 계획에서 소재·쇼핑 상품 등록·파워링크 문구의 조건부를 표시했지만, 이를 모든 산출물에 일관되게 옮기지 못했다.
- 1월 카드 3~7 계산에서 표 금액을 직접 검산하는 과정이 실패했다. 제시한 구간 합은 고정분 포함 총액 18,000,000원과 맞지 않고, 본 행사 검색 한도도 초과했다. 스킬의 규칙대로 걸린 지점으로 되돌아가 수정했어야 하지만, 시나리오의 “좋아요”를 받자 오류를 해결하지 않은 채 완료 메시지까지 냈다.
- 1월 결과 박스 역할 비중(검색 68.9% 등)도 상품·구간 합계가 불일치해 유효하지 않다. 수정 확정본으로 간주하면 안 된다.
