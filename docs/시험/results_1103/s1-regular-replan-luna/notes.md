# 메모

- PROMPT_web의 경로를 사용자가 지정한 `skill/media-mix/` 및 `scenarios/s1-regular-replan/`로 치환해 적용했다. 허용된 업로드 CSV만 읽었다.
- 산출물 초안에서 자체 점검으로 발견한 금액 합계 걸림을 해결하지 못했다. 2판 표는 집행분 상품별 합 1,430,000원인데 제공된 집행 합계는 1,510,000원이며, 상품표 합계와 미포함 브랜드검색 고정분 계산도 총액과 맞지 않는다. 사용자가 수정 입력을 주지 않은 상태에서 임의로 수치를 만들지 않고 미해결로 기록했다.
- 첫 판의 카드 7 예상치 범위 산출이 충분하지 않아 점검 오류 8을 걸림으로 남겼다.
- 시나리오에서 모르는 값으로 넘긴 질문: 카카오 리타겟 노출 단가, 브랜드 메시지 발송 단가, 행사 상세페이지 주소(아직 없음), 행사일 전환율(작년 일별 기록 없음).
- PROMPT_web은 계산 도구 금지라 산술은 직접 계산했다. 결과물 작성은 로컬 산출물 저장을 위해 파일 패치를 사용했다.
