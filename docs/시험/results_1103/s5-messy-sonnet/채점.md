## 설계 미정에 걸린 것
- **D1 · D3 · 준비_보고 2 계열(박스 경계) + T1**: 기대 검색 전환형이 혼합형이 됨. 두 줄 클릭 공유 식(쇼핑 단가 500원으로 클릭을 더 씀)과 캡처 4 클릭 합 6,523 < 지난달 실제 7,602 때문에 일반 + 쇼핑이 490만 → 380만으로 줄고 검색 비중 53.8% → 44.2%. 1차 소넷(45.0% · 혼합형)과 같은 원인이 그대로 남음.
- **D2**: 단가 상승 진단('같은 역할 안에서 옮김')인데 한도 넘는 몫 120만(+차액 10만)을 신규 유입(메타)으로 보냄. 목표 ROAS보다 낮은 메타(줄 ROAS 1.87~2.34)로 옮긴 것도 같은 질문.
- **D13**: 브랜드검색 견적을 묻지 않고(1-다 3번 괄호에서 견적 항목을 뺌) 지난 계약 70만을 '유지 가정'으로 고정분에 둠.
- **D14**: 카카오 단독 리타겟을 모수 모른 채 70만 유지.
- **D16**: 질문은 번호로 3개 이하지만 1-가 3번 "집행 기간 · 컨펌일 (오늘 날짜)", 1-라 2번 "소재 · 쇼핑 등록 · 문구 준비"처럼 한 번호에 답할 값이 셋 넘는 곳이 있음(스킬 본문 문구 그대로).
- **D19**: 인정 기간이 다른 매체 보고 매출(카카오는 구매 수 × 45,000 추정)을 합쳐 '전체 광고비 기준 ROAS 2.50~2.81'로 내고 목표 3.0과 견줌. '매체 보고 기준 — 겹칠 수 있음' 단서는 붙음.
