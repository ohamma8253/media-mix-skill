# notes — s3-new-event (Sonnet, 웹 대화판)

진행: 셸·검색·계산 도구 없이 손계산(결과 파일 조립만 하네스 쪽에서 함). 읽은 것은 PROMPT_web.md, 시나리오 s3, skill/media-mix/ 전부. 상위 폴더 스킬·다른 결과는 열지 않음. 1판 → 광고주 답(11/14) → 2판까지 진행.

## 사용자 역에서 "모르겠어요"로 넘긴 질문
- 목표 ROAS의 매출 기준(자사몰/매체 보고) — 시나리오에 없음, 성과 기준 기본값으로 '확인 전'.
- 월 매출, 객단가의 부가세 포함 여부 — 없음.
- 네이버 쇼핑 상품 등록 · 파워링크 문구 준비, 이미지 소재 여부 — 없음.
- 카카오 모수 — 없음.
- 2판: 예산 "1,200"이 총액인지 추가분인지 — 시나리오에 답 없음 → 스킬 규칙대로 말한 숫자를 총액 12,000,000원으로 보고 '확인 전'.
- 광고주 "4일 연속 좋습니다"가 가리키는 날짜 — 시나리오에 없고, 스킬이 묻지 못함(아래).

## 헷갈린 곳 · 막힌 곳 · 고칠 곳
1. **카드 1-가 3번 vs 하루 요청 (SKILL 카드 3/5, judgment 5절)**: 하루 요청을 3일 연속으로 역제안하는 규칙은 있으나, 대화 중 사용자에게 "앞뒤 날을 써도 되는지"를 언제 물을지 카드에 없음. 1-라 1번 괄호에 임의로 넣어 물음(괄호 보조 둘 안). 카드에 '하루 요청이면 1-라 1번에 앞뒤 날 가능 여부'를 명시하면 좋겠음.
2. **영상 가용일 vs 연속 일수**: 영상이 11/25 업로드분이라 "소재 가용일 규칙"으로 메타 시작을 11/25로 잡아 3일이 됨. 광고주 답의 "4일 연속"과 어긋났고, 스킬 어디에도 이 불일치를 다룰 줄이 없음(카드 10 '광고주 답을 받은 뒤'는 숫자 모호 시 한 번 묻기만 있음). 2판 첫 차례의 질문 3개 상한(앵콜 대상·총액·성과 기준) 때문에 "4일"의 날짜를 묻지 못하고 7칸 '결정 부탁'으로 넘김 → 질문 우선순위 규칙이 필요함. 이미지 소재 여부는 1-라 2번에서 답이 비어 '확인 못 함'으로 두어 이 불일치가 생김.
3. **리타겟 분리 기준**: "모수가 작으면 합친다"의 '작다'에 숫자가 없음(8만을 작다고 볼지). 이번엔 하한 대비 넉넉하다고 보고 분리하고 판단 차이로 적음. 기준 숫자나 하한 대비 비율이 있으면 좋음.
4. **리타겟 한도 식**: "모수 × 1회 × 노출 단가 ÷ 1000"에서 노출 단가 범위 중 어느 값(낮은 끝/가운데)을 쓸지 정해져 있지 않음. 보수적으로 낮은 끝(8,000원)을 썼음. 파워링크 한도는 가운데(350원)를 써서 서로 기준이 다름 — 통일 규칙 필요.
5. **파워링크 한도와 예상 클릭 범위**: 한도 검사는 가운데 클릭 단가, 예상 수치는 범위(300~400)라 낮은 끝으로 보면 클릭이 한도(75)를 넘음(83). 카드 5의 "같은 값 · 같은 근거"와 범위 표기가 충돌함.
6. **브랜드검색 고정분**: 7일 계약 11/25~12/1은 1판 기간(11/25~11/27) 밖(11/28~12/1)을 포함. 계약 기간이 구간 표 밖에 걸칠 때 쓰는 표기가 없어 '고정분' 열을 따로 둠. 결과 박스 분모에 넣는지는 문서대로 두 경우를 적음.
7. **결과 박스 분모(구간)**: 고정분이 구간에 속하지 않아 본 행사 구간 금액에는 뺐고 꼬리표로만 처리함.
8. **카드 7 필요 전환율**: 신규·리타겟·브랜드 키워드별로 클릭 단가를 가정해 역산해야 해서, 합계가 아닌 상품별 한 줄씩 적음. 양식이 상품별인지 합계인지 불분명.
9. **확인 못 함 건수**: 값 하나=한 줄 규칙인데 '시즌 근거'(작년 기록·데이터랩 두 값), '실제 객단가/부가세 여부'를 한 줄로 셀지 두 줄로 셀지 애매함. 이번엔 시즌 근거 1줄, 객단가·부가세 2줄로 셈.
10. **✋ 1에서 "그대로 가요"**: 비슷한 광고주 기록의 광고 상품 확인 질문(브랜드 키워드 전환율)에 구체 답이 없어 '확인 못 함'으로 한 건을 더함 — 시나리오 답이 포괄적일 때의 처리 규칙이 스킬에 없음(내가 만든 처리).
11. **사전 심의 업종 짐작**: 입력 카드에 '짐작'으로 두었으나 ✋ 1 질문 1번 괄호에서만 확인받는 구조. 시나리오의 "아니에요"는 직접 묻지 않아 쓰지 못함.
12. **목표 매출 숫자**: 1-가 1번에서 괄호 둘 제한으로 목표 매출 숫자를 묻지 못함(입력 카드 '묻지 않음'). 새 광고주 1번에서 목표 숫자가 빠지는 점이 아쉬움.
13. **2판 합의 단계**: 시나리오의 "광고주 최종 답(11/15)" 문항은 스킬이 묻지 않아 쓰지 않음. 최종 상태는 '광고주 확인 대기'로 끝남(역제안 결정 '4일 연속' 미확정).
14. **컨펌 마감 "바로"**: 날짜가 아니어서 11/16(제안)을 만들었음. '바로'일 때의 기본 날짜 규칙이 없음.
15. **구간 이름 중복**: 2판에서 예열이 두 번(11/25~26, 11/30) 나옴. "다른 이름을 만들지 않는다"와는 충돌 없으나 같은 이름 반복 표기 규칙이 불분명.
