# 예시 결과물 — 줄거리 네 건 + 부록 (10/29 축 정리, 10/30 산출물 한 벌)

> **v2.0 이전(10/30) 규칙으로 만든 예시다** — 리타겟 한도 계산 · 결과 박스 이름이 지금(v2.0)과 다르다. 지금 규칙은 [`skill/media-mix/`](../../skill/media-mix/SKILL.md)와 [`CHANGELOG.md`](../../CHANGELOG.md)를 본다.

상황은 **입구**(상시 / 새 광고주) × **기간 모양**(평시 / 행사 / 장기)으로 나눈다(10/29 확정). 결과물은 어떤 상황이든 **같은 여덟 산출물 한 벌**로 나온다(10/30 확정, `결과물_산출물한벌_1030.md`(공개본에 없음)). 상황이 바꾸는 것은 산출물 안의 줄과 '해당 없음'뿐이다. 1~2개월은 일곱 칸에 달 열을 더하는 분기, 인하우스는 운영 패스라 부록이다.
- **전부 가상이다.** 검색량 · 단가 · 전환율 · 모수는 규칙이 돌아가는 모습을 보여 주려고 넣은 예시 입력이다. 업계 기준값이 아니다. 가정마다 근거 유형(지난 기록 / 비슷한 광고주 / 매체 예상값 / AI 추정)을 붙였다.
- **기준 사례를 대신하지 않는다.** 정답지는 사람이 직접 짠 실제 사례 두 건이다(공개본에 없음). 줄거리 1의 1판은 사례 2, 줄거리 2는 사례 1과 같은 자리다.
- 금액 합 · 구간 합 · 검색 한도 · 리타겟 한도 · 학습 하한 · 예상 수치 범위는 스크립트로 계산하고 검산했다(예시 생성 스크립트는 공개본에 없음).

## 만들면서 드러난 것
**규칙의 빈틈 — 점검 규칙표 · 설계에 가안으로 넣음**(설계 9장 11번)
1. **브랜드 키워드에도 검색 한도가 걸린다.** 작은 브랜드는 한도가 몇만 원뿐이다(줄거리 2: 월 4.2만 원, 줄거리 4의 12월: 2.7만 원). 줄거리 2 · 3 · 4의 처음 안과 줄거리 1의 2판 본 행사 구간이 모두 이 한도를 넘어서 고쳤다. 브랜드 검색 클릭률 값의 출처가 없어 예시는 30%로 가정했다.
2. **며칠짜리 행사의 리타겟 한도**: 식이 '월 노출 빈도'로 적혀 있어 4일 행사에 쓸 수 없었다. 하루 1회 × 일수로 셌다(줄거리 3).
3. **학습 하한에 넣을 구매 단가**: 예상이 범위라 어느 값을 쓸지 정해 둔 것이 없었다. 가운데 값으로 계산하고, 위쪽 끝으로는 미달이면 판정 조건을 붙였다.
4. **다시 짤 때 이미 쓴 돈**: 2번에 '집행분' 고정 줄로 두고 남은 금액만 다시 나눴다(줄거리 1). 설계 4장에 넣었다.

**판단이 남는 곳 — 확인 필요**
- **목표 매출과 목표 ROAS가 함께 안 맞을 때**(줄거리 2): 매출 목표로 역산한 총액에서는 ROAS가 목표에 못 미친다. 지금은 5번에 한 줄로 적기만 한다(설계 9장 6번).
- **전략안의 방향 비중이 한도에 막힐 때**(줄거리 4의 1월): 검색광고 35%를 잡았지만 검색 한도 때문에 26%까지만 갔다. 출발 비중(9장 9번)을 정할 때 한도를 넘는 비중은 쓰지 않는 것이 맞는지 확인이 필요하다.
- **행사 당일 브랜드 검색 증가**(줄거리 3): 작년 기록이 없으면 배수를 못 넣어 한도가 작게 잡힌다. 운영 중 증액으로 둘지, 비슷한 광고주 배수를 쓸지.

**배분 유형 지도에서**(박스가 아니라 박스 안의 배분 모양): 줄거리 1 · 부록(검색 수확형), 2 · 3(피드 판매형), 4의 12월(알리기형) → 1월(검색 수확형 경계)로 세 칸이 모두 나왔다. 운영 패스(부록)와 판(1의 1판 → 2판)은 점을 거의 옮기지 않았다.
